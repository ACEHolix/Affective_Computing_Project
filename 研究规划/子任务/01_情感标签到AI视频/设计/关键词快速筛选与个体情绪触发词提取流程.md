# 关键词快速筛选与个体情绪触发词提取流程

日期：2026-03-31

## 文档目的

本文件用于回答：

- 如何让被试者从一批关键词中快速找到那些最容易引发其强烈情感变化的词
- 如何区分喜欢、厌恶、害怕、恶心、自我相关等不同类型的触发词
- 如何把这个过程做成可量化、可结构化、可接入后续视频生成系统的流程

## 先给结论

最有效的方法不是：

- 一次性给被试一大堆词，让他慢慢挑

而是：

- 先分组
- 再快筛
- 再精筛
- 再做对比排序
- 最后用小样本校准

也就是说，建议采用：

1. 分桶词库
2. 快速筛查
3. 多维评分
4. 强制排序
5. 小样例验证

## 一、为什么不能直接让被试“从很多词里挑”

直接从几百个词里自由挑选，常见问题是：

1. 认知负担太高
2. 很多人对自己真实触发点并没有稳定自知
3. “喜欢”和“强情绪触发”容易混淆
4. 不同词之间很难横向比较
5. 最终结果不稳定，重复测量一致性低

因此需要一个有结构的提取流程。

## 二、推荐的整体流程

建议分成 5 步：

1. 词库分组
2. 第一轮快筛
3. 第二轮多维精筛
4. 组内与跨组排序
5. 样例刺激验证

## 三、步骤 1：词库分组

### 目的

- 降低认知负担
- 让被试先在语义类别中定位，再找具体触发词

### 推荐分组方式

建议至少分为以下几类：

1. 场景类
   - 海边
   - 医院
   - 教室
   - 夜路
   - 车站
   - 家

2. 关系类
   - 重逢
   - 离别
   - 陪伴
   - 被理解
   - 背叛
   - 孤独

3. 感官类
   - 雨声
   - 海浪
   - 心跳
   - 霓虹
   - 黑暗
   - 低频轰鸣

4. 物体类
   - 旧照片
   - 药瓶
   - 花束
   - 玩具
   - 行李箱
   - 门牌

5. 主题类
   - 成长
   - 失败
   - 怀念
   - 希望
   - 失控
   - 安全感

### 输出

- 每类一个词列表
- 每个词附唯一 ID

## 四、步骤 2：第一轮快筛

### 目的

- 迅速从大词库中筛出有反应的词
- 不在第一轮就做复杂细分

### 推荐任务形式

每个词只做一个快速判断：

- `没有明显感觉`
- `有一点感觉`
- `有明显感觉`

或者：

- 0 到 2 分

### 推荐问题

请判断这个词是否会让你产生明显情绪波动：

- 0 = 基本没有感觉
- 1 = 有一点感觉
- 2 = 明显有感觉

### 为什么有效

- 大幅降低首轮负担
- 先筛出高反应词，再做细分

### 输出

- 每类保留前若干个高反应词
- 总体建议保留 20 到 40 个词进入下一轮

## 五、步骤 3：第二轮多维精筛

### 目的

- 区分不同类型的情绪触发
- 避免把“喜欢”误判成“高强度触发”

### 每个词建议评分维度

对每个入围词，至少评分以下项目：

1. 喜欢度
2. 厌恶度
3. 害怕感
4. 恶心感
5. 自我相关性
6. 熟悉度
7. 情绪触发强度

### 推荐量表

- 1 到 5 分
或
- 1 到 7 分

### 示例问题

看到“夜路”这个词时，请分别评分：

- 你有多喜欢这个词对应的场景
- 你有多厌恶这个词对应的场景
- 它让你感到多害怕
- 它让你感到多恶心
- 它与你的个人经历有多相关
- 它对你有多熟悉
- 它能多大程度引发你的情绪变化

### 输出

- 每个词形成一个多维向量

例如：

```json
{
  "keyword": "夜路",
  "like": 2,
  "dislike": 4,
  "fear": 5,
  "disgust": 1,
  "self_relevance": 4,
  "familiarity": 5,
  "intensity": 5
}
```

## 六、步骤 4：排序与对比

### 目的

- 解决“每个词都打高分”导致区分度不足的问题
- 找到真正排在最前面的触发词

### 推荐方法 1：组内 Top-K 排序

要求被试在每一类中选出：

- 最喜欢的前 5 个
- 最厌恶的前 5 个
- 最害怕的前 5 个
- 最恶心的前 5 个
- 最容易引发强烈情绪变化的前 5 个

### 推荐方法 2：两两比较

给出两个词，让被试快速判断：

- 哪个更让你害怕
- 哪个更让你恶心
- 哪个更容易打动你
- 哪个和你更相关

### 为什么重要

- 评分题容易出现“虚高”
- 比较题更容易形成稳定排序

### 输出

- `positive_trigger_keywords`
- `negative_trigger_keywords`
- `fear_trigger_keywords`
- `disgust_trigger_keywords`
- `self_relevant_keywords`
- `high_intensity_keywords`

## 七、步骤 5：样例刺激验证

### 目的

- 防止“关键词层面高分”但真实内容诱发不强
- 验证关键词是否真的能转化为有效刺激

### 做法

从高分关键词中自动组合成若干个小样例：

- 文本描述
- 小图像提示
- 短视频 prompt

例如：

- “黄昏、海边、重逢、钢琴声”
- “夜路、雨声、孤独、低频环境声”

然后让被试再评分：

- 喜欢度
- 自我相关性
- 情绪类别
- 情绪强度
- 是否愿意继续看类似内容

### 输出

- 验证后的高可信触发词集合
- 词到场景/风格/声音的初步映射

## 八、推荐的评分维度设计

如果只想保留最核心维度，建议至少保留以下 6 个：

1. `like`
2. `dislike`
3. `fear`
4. `disgust`
5. `self_relevance`
6. `intensity`

如果条件允许，再增加：

7. `familiarity`
8. `sadness`
9. `calmness`
10. `arousal`

## 九、推荐的最终数据结构

建议最后把结果整理为两层：

### 第一层：词级结果

```json
{
  "keyword": "海边",
  "group": "scene",
  "scores": {
    "like": 5,
    "dislike": 1,
    "fear": 1,
    "disgust": 1,
    "self_relevance": 4,
    "familiarity": 5,
    "intensity": 4
  }
}
```

### 第二层：个体情绪触发总结

```json
{
  "positive_trigger_keywords": ["海边", "重逢", "晚霞"],
  "negative_trigger_keywords": ["医院", "离别", "夜路"],
  "fear_trigger_keywords": ["黑暗", "追逐", "尖叫"],
  "disgust_trigger_keywords": ["腐烂", "污渍", "异味"],
  "self_relevant_keywords": ["教室", "旧照片", "雨天"],
  "high_intensity_keywords": ["离别", "夜路", "重逢"]
}
```

## 十、推荐的最小可行版本

如果你当前只想做一个快速版本，建议：

1. 准备 100 到 150 个分组关键词
2. 第一轮做 0 到 2 分快筛
3. 每类保留前 10 个词
4. 第二轮对入围词做 6 维评分
5. 每类做 Top-5 排序
6. 最后生成 6 到 10 条组合样例做验证

## 十一、对子任务 01 的直接意义

这套流程的价值在于：

1. 可以快速找到真正高价值的个体触发词
2. 可以把“词”转成后续的视频内容控制线索
3. 可以区分：
   - 喜欢的内容
   - 厌恶的内容
   - 害怕的内容
   - 恶心的内容
   - 与自己最相关的内容

这比直接问“你喜欢什么视频”更细，也更适合个体化情绪诱发系统。

## 十二、当前结论

要让被试快速从一堆关键词中找到真正高情绪触发词，最实用的方法是：

1. 分组降低负担
2. 快筛找高反应词
3. 多维评分区分情绪类型
4. 排序形成优先级
5. 用小样例验证是否真的有效

这个流程既适合问卷，也适合做成实验前的个体化校准模块。
