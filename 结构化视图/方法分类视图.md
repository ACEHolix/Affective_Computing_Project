# 方法分类视图

## 目的

本文件用于把当前已收集的 EEG 情感识别文献整理成方法分类视图，方便后续直接写入综述中的“方法综述”部分。

当前分类基于现有文献池，优先强调近两年的研究热点，而不是追求完整覆盖所有历史方法。

## 一、传统机器学习方法

### 典型特点

- 依赖手工特征
- 对小样本数据相对稳健
- 可解释性通常较强
- 在跨被试泛化方面通常不如深度模型与迁移学习方法

### 当前文献状态

- 当前文献池里这类论文相对偏少
- 已经发现一些补充方向，尤其是时间域特征、差分熵、功率谱特征与调参后的机器学习方法

### 当前可用文献线索

- *A comparative analysis of emotion recognition from EEG signals using temporal features and hyperparameter-tuned machine learning techniques* (2025)
- *EEG-based emotion recognition systems; comprehensive study* (2024 review)

### 写作建议

这部分在综述中不宜写太长，但必须保留。原因是：

- 它构成深度学习方法的对照基线
- 很多新方法仍然以传统特征作为输入
- 评价“是否真的进步”时不能完全跳过传统方法

## 二、CNN 与时空卷积方法

### 典型特点

- 适合处理 EEG 的局部空间结构与时间片段模式
- 常见做法是把 EEG 转成二维特征矩阵、拓扑图或时空块
- 很多工作通过卷积自动替代部分手工特征设计

### 代表文献

- *Convolution spatial-temporal attention network for EEG emotion recognition* (2024)
- *EEG Emotion Recognition Network Based on Attention and Spatiotemporal Convolution* (2024)
- *CATM: A Multi-Feature-Based Cross-Scale Attentional Convolutional EEG Emotion Recognition Model* (2024)

### 观察

- 当前 CNN 类研究已经很少是“纯 CNN”
- 更多工作倾向于把卷积和注意力、多尺度特征或图结构结合

## 三、RNN / LSTM / BiLSTM 与混合模型

### 典型特点

- 强调 EEG 时序动态建模
- 常与 CNN 搭配，形成 CNN-LSTM 或 CNN-BiLSTM 结构
- 适合写成“过渡架构”：连接传统深度模型与更复杂时空模型

### 代表文献

- *Spatio-temporal CNN-BiLSTM dynamic approach to emotion recognition based on EEG signal* (2025)
- *EEG emotion recognition based on differential entropy feature matrix through 2D-CNN-LSTM network* (2024)

### 观察

- 这类模型仍然有代表性，但在当前热点中已不如图网络、注意力和 Transformer 显眼
- 在综述里更适合作为“经典深度学习架构演化链条”中的一环

## 四、图神经网络方法

### 典型特点

- 把 EEG 通道之间的关系建模为图
- 适合表达脑区连接关系、空间拓扑与功能耦合
- 是近两年最集中的技术热点之一

### 代表文献

- *A temporal-spectral graph convolutional neural network model for EEG emotion recognition within and across subjects* (2024)
- *EEG-based emotion recognition using graph convolutional neural network with dual attention mechanism* (2024)
- *Graph Convolutional Network With Connectivity Uncertainty for EEG-Based Emotion Recognition* (2024)
- *Automatically Extracting and Utilizing EEG Channel Importance Based on Graph Convolutional Network for Emotion Recognition* (2024)
- *Emotion recognition using multi-scale EEG features through graph convolutional attention network* (2025)

### 可再细分的子方向

- 时频图卷积
- 图注意力
- 通道重要性建模
- 不确定性图建模
- 多尺度图特征融合

### 观察

- 图神经网络不是一个单独点状方向，而是当前 EEG 情感识别中的主干架构之一
- 如果正文篇幅允许，图网络部分值得单独分成一个完整小节

## 五、注意力机制方法

### 典型特点

- 不一定独立成类，但在近期文献中几乎无处不在
- 常用于强调：
  - 关键通道
  - 关键频带
  - 关键时间片段
  - 关键脑区连接

### 代表文献

- *EEG Emotion Recognition Network Based on Attention and Spatiotemporal Convolution* (2024)
- *HASTF: a hybrid attention spatio-temporal feature fusion network for EEG emotion recognition* (2024)
- *CATM: A Multi-Feature-Based Cross-Scale Attentional Convolutional EEG Emotion Recognition Model* (2024)
- *EEG-based emotion recognition using graph convolutional neural network with dual attention mechanism* (2024)

### 写作建议

注意力机制不建议完全作为独立主章节，而更适合作为“贯穿不同模型的通用设计策略”来写。

## 六、Transformer 方法

### 典型特点

- 更强调长程依赖建模
- 常结合 EEG 结构先验、脑区关系或跨被试泛化目标
- 是当前非常值得重点写的新方向

### 代表文献

- *EmT: A Novel Transformer for Generalized Cross-Subject EEG Emotion Recognition* (2025)

### 观察

- Transformer 在当前文献池中数量还不如图模型多
- 但它的研究价值很高，特别适合放在“前沿方向”和“未来趋势”部分重点讨论

## 七、跨被试泛化与域适应方法

### 典型特点

- 直接针对 subject-independent / cross-subject 情况
- 核心目标是减少不同被试间分布差异
- 是近两年最明显的研究重心之一

### 代表文献

- *Multi-source Selective Graph Domain Adaptation Network for cross-subject EEG emotion recognition* (2024)
- *Domain adaptation spatial feature perception neural network for cross-subject EEG emotion recognition* (2024)
- *Multi-source domain adaptation for EEG emotion recognition based on inter-domain sample hybridization* (2024)
- *EmT: A Novel Transformer for Generalized Cross-Subject EEG Emotion Recognition* (2025)

### 可再细分的子方向

- 单源域适应
- 多源域适应
- 被试不变表示学习
- 结构先验约束下的跨被试建模

### 观察

- 这一类方法不只是一个模型类别，更像是当前领域的“问题导向主线”
- 如果想让你的综述有辨识度，这部分应作为重点章节

## 八、多模态 EEG-centered 方法

### 典型特点

- EEG 仍是核心模态
- 结合 EOG、fNIRS、外周生理信号等提高鲁棒性
- 当前趋势从简单拼接走向可信度建模与跨模态一致性建模

### 代表文献

- *Cross-modal credibility modelling for EEG-based multimodal emotion recognition* (2024)
- *Multimodal Emotion Recognition Based on EEG and EOG Signals Evoked by the Video-Odor Stimuli* (2024)
- *EEG-fNIRS-Based Emotion Recognition Using Graph Convolution and Capsule Attention Network* (2024)

### 写作建议

如果你的综述主要聚焦 EEG 单模态，可以把这一部分作为扩展章节，而不是正文主轴。

## 九、轻量模型与部署导向方法

### 典型特点

- 更关注计算开销、实时性或工程可部署性
- 不一定追求最复杂的模型设计

### 代表文献

- *Brain-inspired modular echo state network for EEG-based emotion recognition* (2024)
- *Real-time EEG-based emotion recognition for neurohumanities: perspectives from principal component analysis and tree-based algorithms* (2024)

### 观察

- 当前这类研究数量不多，但很适合写在“未来方向”和“实际应用”部分

## 当前方法分类下的总体判断

基于当前文献池，方法层面的整体趋势可以概括为：

1. 图神经网络仍然是主流热点
2. 注意力机制已经成为通用增强模块
3. Transformer 正在进入高价值前沿方向
4. 跨被试泛化与域适应比单纯提升被试内精度更值得重点讨论
5. 多模态和轻量部署方向是值得保留的扩展板块

## 建议的正文组织方式

方法部分建议按以下顺序写：

1. 传统机器学习
2. CNN / 时空卷积
3. RNN / LSTM / 混合模型
4. 图神经网络
5. Transformer 与注意力机制
6. 跨被试泛化与域适应
7. 多模态 EEG-centered 方法
8. 轻量部署与实时应用
