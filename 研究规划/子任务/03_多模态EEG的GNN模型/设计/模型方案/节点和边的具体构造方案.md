# 节点和边的具体构造方案

## 目的

本文件用于把“图怎么建”这件事具体化，避免后续停留在抽象概念层面。

## 一、节点构造方案

## 方案 1：EEG 通道节点 + 外周模态节点

### 节点定义

- EEG：每个通道一个节点
- ECG：1 个节点
- RESP：1 个节点
- EDA：1 个节点

### 优点

- 最简单
- 最容易实现
- 最适合第一版

### 缺点

- 外周模态内部结构表达不够细

## 方案 2：EEG 通道节点 + 外周特征节点

### 节点定义

- EEG：每个通道一个节点
- ECG：按特征拆成多个节点
- RESP：按特征拆成多个节点
- EDA：按特征拆成多个节点

### 优点

- 图更丰富
- 更适合复杂融合

### 缺点

- 设计复杂
- 初版不建议直接使用

## 方案 3：脑区节点 + 外周模态节点

### 节点定义

- EEG：先按脑区聚合，再把脑区作为节点
- ECG/RESP/EDA：模态节点

### 优点

- 更紧凑
- 更容易解释

### 缺点

- 细粒度 EEG 信息会丢失

## 当前推荐节点方案

第一版推荐：

**方案 1：EEG 通道节点 + 外周模态节点**

原因：

- 最适合先跑通
- 结构足够清晰
- 后续也好扩展

## 二、边构造方案

图中至少会存在三类边：

1. EEG 内部边
2. 外周模态内部边
3. 跨模态边

## 1. EEG 内部边

### 方案 A：按电极空间邻近建边

做法：

- 相邻电极连边
- 或按距离阈值建边

优点：

- 简单稳定
- 很适合第一版

### 方案 B：按功能连接建边

做法：

- 计算通道间相关性、coherence、PLV 等

优点：

- 更有生理意义

缺点：

- 更依赖预处理质量

### 当前推荐

第一版建议先用：

- 空间邻近图

后续再尝试功能连接图。

## 2. 外周模态内部边

### 第一版建议

如果 ECG、RESP、EDA 各自只用一个节点，那么：

- 不需要内部边

如果后续拆成多个特征节点，则可按特征相关性建边。

## 3. 跨模态边

### 方案 A：EEG 所有节点连接到每个外周模态节点

做法：

- 所有 EEG 节点都与 ECG、RESP、EDA 节点相连

优点：

- 最简单
- 易于实现

缺点：

- 连接过多，可能过于粗糙

### 方案 B：脑区-模态选择性连接

做法：

- 只连接某些脑区节点和某些模态节点

优点：

- 更有生理合理性

缺点：

- 需要先验知识

### 方案 C：可学习跨模态边

做法：

- 初始给一个稀疏连接
- 边权由模型学习

优点：

- 灵活

缺点：

- 更复杂

## 当前推荐边方案

第一版建议：

- EEG 内部边：空间邻近
- 外周模态：单节点，不建内部边
- 跨模态边：EEG 全节点连接到各模态节点

这虽然简单，但足够作为最小可行版本。

## 三、加入眼动后的构造方式

如果后续加入眼动，推荐：

- 眼动作为一个新的模态节点
  或
- 眼动按特征拆成若干节点

第一版建议：

- 先作为一个模态节点

## 四、加入 EGG 后的构造方式

如果后续加入 EGG，建议：

- 第一阶段先把 EGG 当作一个模态节点

原因：

- EGG 在当前任务里更偏探索性
- 不建议一开始就把它做得过细

## 五、第一版可直接落地的图结构

假设：

- EEG 有 `N` 个通道
- ECG、RESP、EDA 各 1 个节点

那么整张图可以包含：

- `N + 3` 个节点

边包括：

- EEG 通道间空间边
- 每个 EEG 节点到 ECG 节点的边
- 每个 EEG 节点到 RESP 节点的边
- 每个 EEG 节点到 EDA 节点的边

如果后续加入眼动和 EGG，则扩展为：

- `N + 5` 个节点

## 六、当前推荐的实施顺序

1. 先实现最简单节点方案
2. 先实现最简单跨模态边
3. 验证图模型是否优于普通融合
4. 再逐步改进：
   - 功能连接图
   - 可学习边权
   - 动态图
   - 异构图

## 七、当前结论

对你目前的任务来说，最合理的第一版图构造方案是：

**EEG 通道节点 + ECG/RESP/EDA 模态节点 + EEG内部空间边 + 全连接跨模态边**

这是最适合快速验证想法、也最容易往后扩展的方案。
