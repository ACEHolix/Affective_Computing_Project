# 多模态EEG的GNN模型相关文献

## 说明

本文件整理“子任务 03：适合分析多模态EEG数据的GNN类模型”的第一轮相关文献。

本轮筛选标准是：

- 优先保留和 EEG 主模态直接相关的多模态研究
- 优先保留使用 GNN、图卷积、图注意力、异构图或动态图的方法
- 如果文献不是严格的“EEG 多模态 + GNN”，但对后续模型设计有直接启发，也作为邻近参考保留

## 五、从当前文献得到的直接启发

基于这一轮检索，子任务 3 可以明确得到几个方向判断：

### 1. EEG + fNIRS 是当前最成熟的“多模态 + 图模型”切入点

原因是：

- 文献已经存在
- 脑信号间关系天然适合图建模
- 比 EEG + 文本/视频 这类跨度更大的融合更自然

### 2. 子任务 3 不应直接从“最复杂异构图”开始

更稳的路线是：

1. 单模态 EEG GNN 基线
2. 双模态简单融合基线
3. 多模态图融合
4. 动态图 / 注意力 / 跨被试增强

### 3. 跨模态关系建模比“简单拼接”更值得做

从当前文献看，真正有价值的创新不在于把多模态特征拼起来，而在于：

- 如何表达模态间关系
- 如何动态调整模态权重
- 如何处理模态可靠性差异

### 4. 如果要做论文题目，最好把“泛化”也并进来

单纯“多模态 GNN”已经有一定工作基础。更有辨识度的切口是：

- 多模态 GNN + cross-subject
- 多模态 GNN + 动态图
- 多模态 GNN + 模态可信度

## 六、当前建议的最小研究路线

### 路线 A：稳妥型

1. 选 EEG + fNIRS
2. 建单模态 EEG GCN 基线
3. 建简单多模态融合基线
4. 建多模态图模型
5. 比较性能和模态贡献

### 路线 B：更有创新性的路线

1. 选 EEG + fNIRS 或 EEG + EOG
2. 构建模态内图 + 跨模态图
3. 引入动态邻接或图注意力
4. 加入 cross-subject 评价
5. 做模态可信度或边权可解释分析
