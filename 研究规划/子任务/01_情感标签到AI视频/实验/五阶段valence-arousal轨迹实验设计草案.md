# 五阶段 valence-arousal 轨迹实验设计草案

日期：2026-03-31

## 文档目的

本文件用于评估并整理以下实验构想是否合理：

- 用一个五阶段流程来控制视频诱发过程中的 valence 和 arousal 轨迹变化

目标不是只判断“能不能做”，而是进一步明确：

- 哪些部分符合现有文献结论
- 哪些部分在实验上有难点
- 如何把这条轨迹改造成更可执行的实验方案

## 一、原始构想

整个过程划分为五个阶段：

### 阶段 1

- Valence：由中性上升至正向
- Arousal：由低水平上升至高水平

### 阶段 2

- Valence：维持在正向水平
- Arousal：由高水平逐渐下降

### 阶段 3

- Valence：由正向下降至负向
- Arousal：维持在低水平

### 阶段 4

- Valence：维持在负向水平
- Arousal：由低水平上升至高水平

### 阶段 5

- Valence：由负向回升至中性
- Arousal：由高水平逐渐下降

## 二、总体判断

这条轨迹在研究逻辑上是合理的。

它的优点在于：

1. 不是只做离散情绪类别切换，而是在显式操控连续情绪轨迹
2. 同时考虑了 valence 与 arousal 两个维度
3. 包含上升、维持、下降、恢复几个重要过程
4. 非常适合对子任务 01 的“情绪轨迹驱动视频生成”进行实验化验证

但如果结合现有文献和情绪诱发的一般规律，当前版本还存在两个主要难点：

1. 第 3 阶段不够自然
2. 第 5 阶段恢复目标可能过强

同时，从实验可执行性的角度看，还有第三个问题：

3. 缺少一个被单独定义的 `neutral baseline`

也就是说：

- 目前的五阶段轨迹本身可以保留
- 但正式实验不建议直接从阶段 1 开始
- 更合理的组织方式是：
  - `阶段 0：baseline`
  - `阶段 1 到阶段 5：目标轨迹`

## 二点五、最终建议

结合目前文献和实验控制需求，我的判断是：

### 1. 五阶段轨迹可以保留

原因：

- 它的研究问题清楚
- 能覆盖激活、缓和、转负、强化、恢复几个关键过程
- 对“个体化是否改善情绪轨迹控制”这一问题很有价值

### 2. 但不建议把它作为唯一版本

更合理的做法是同时保留两个版本：

1. `完整版：0 + 5 阶段`
   - 用于正式主实验

2. `简化版：0 + 4 阶段`
   - 用于 pilot / smoke test / 参数预实验

### 3. 最需要修改的不是“删掉整个设计”，而是：

- 加一个单独 baseline
- 把阶段 3 说得更精确
- 把阶段 5 改成恢复到中性附近
- 明确简化版何时使用

## 三、为什么整体方向是合理的

### 1. 连续情绪轨迹比单点情绪标签更贴近真实体验

现实中的情绪变化往往不是：

- 中性 -> 快乐 -> 结束

而更像：

- 激活
- 维持
- 转折
- 强化
- 缓和

因此，用阶段化轨迹来组织视频，比只做单段静态情绪更有研究价值。

### 2. 文献支持高 arousal 更容易被拉起，低 arousal 恢复更慢

从前面整理的文献判断：

- `low -> high arousal` 通常较容易
- `high -> low arousal` 通常较慢，需要恢复段

这意味着：

- 阶段 1 合理
- 阶段 2 合理
- 阶段 4 合理
- 阶段 5 需要设计成真正的恢复段

### 3. 文献支持负性状态更容易持续

当前已有文献和情绪惯性研究普遍支持：

- 负性状态通常更容易持续
- 从负向状态恢复到中性比从中性进入负向更难

这意味着：

- 阶段 5 是合理的目标
- 但不宜把目标设得过强，不应默认完全恢复

## 四、逐阶段评估

## 阶段 1：中性 -> 正向；低 arousal -> 高 arousal

### 判断

- 合理

### 对应的情绪原型

- 兴奋
- 欢快
- 激活感
- 奖励感

### 视频特征建议

- 明亮色调
- 节奏增强
- 上升型音乐
- 积极事件推进
- 奖励或成就线索

### 风险

- 如果刺激过强，后续阶段恢复难度会上升

## 阶段 2：正向维持；高 arousal -> 低 arousal

### 判断

- 合理

### 对应的情绪原型

- 兴奋转满足
- 热烈转舒缓
- 开心转平静

### 视频特征建议

- 保持正性内容
- 降低剪辑密度
- 降低音乐张力
- 增加稳定画面和缓和节奏

### 风险

- 如果节奏下降过快，可能导致被试看作“无聊”而非“平静”

## 阶段 3：正向 -> 负向；低 arousal 维持

### 判断

- 有理论可能，但当前表述不够精确

### 核心问题

一般情况下：

- `valence 正 -> 负` 往往会伴随 arousal 上升

因此，如果你要求：

- valence 明显转负
- arousal 一直低

那它就不再适合表示一般负向情绪，而更适合表示：

- 悲伤
- 空虚
- 失落
- 孤独
- 无助

### 建议改写

不要把阶段 3 写成一般性的“转负”，建议明确写为：

- `由正向转入低唤醒负向状态`

### 视频特征建议

- 减少冲突爆发
- 使用离别、错过、落空、独处等低唤醒负性母题
- 节奏保持缓慢
- 音乐由温暖转为冷淡或稀疏

### 风险

- 如果内容选得不对，很容易把 arousal 也一起拉高

## 阶段 4：负向维持；低 arousal -> 高 arousal

### 判断

- 合理

### 对应的情绪原型

- 悲伤转压迫
- 失落转紧张
- 低落转恐惧或焦虑

### 视频特征建议

- 保持负向基调
- 增加不确定性或压迫线索
- 提升声音密度
- 增加镜头运动或张力

### 风险

- 若刺激强度控制不好，容易过冲

## 阶段 5：负向 -> 中性；高 arousal -> 低 arousal

### 判断

- 合理，但当前目标应更保守

### 核心问题

结合文献：

- 负向状态恢复本来就慢
- 高 arousal 回落也通常需要时间

因此阶段 5 更应被理解为：

- `恢复段`
- `de-escalation`
- `toward neutral`

而不是保证完全回到纯中性

### 建议改写

把阶段 5 改成：

- `Valence：由负向回升至中性附近`
- `Arousal：由高水平逐渐下降至低到中等水平`

### 视频特征建议

- 引入安全线索
- 减少冲突密度
- 使用稳定镜头
- 使用更柔和的环境音和视觉元素

### 风险

- 如果阶段 4 太强，阶段 5 的恢复会不充分

## 五、当前建议采用的五阶段轨迹

结合文献和实验可操作性，更推荐的版本如下：

### 阶段 0：neutral baseline

- Valence：中性
- Arousal：低到中低

说明：

- 这一阶段不计入五阶段主体
- 但在正式实验中必须存在
- 用于提供稳定的前测基线与恢复参考

### 阶段 1：正向激活

- Valence：中性 -> 正向
- Arousal：低 -> 高

### 阶段 2：正向缓和

- Valence：维持正向
- Arousal：高 -> 中低

### 阶段 3：转入低唤醒负向

- Valence：正向 -> 负向
- Arousal：维持低到中低

### 阶段 4：负向强化

- Valence：维持负向
- Arousal：低 -> 高

### 阶段 5：恢复段

- Valence：负向 -> 中性附近
- Arousal：高 -> 低

### 轨迹使用原则

这条轨迹当前应被理解为：

- 第一版实验主线
- 用于评估个体化视频是否优于通用视频的标准轨迹

而不应被理解为：

- 对所有用户都完全相同的唯一情绪路线

也就是说：

- 五阶段轨迹负责定义实验目标
- 个体画像负责决定每一阶段的视频具体内容与风格

## 五点五、推荐的简化版四阶段轨迹

如果当前优先目标是先验证系统可行性，而不是一步到位做完整主实验，更推荐先用四阶段简化版。

### 阶段 0：neutral baseline

- Valence：中性
- Arousal：低到中低

### 阶段 1：正向激活

- Valence：中性 -> 正向
- Arousal：低 -> 高

### 阶段 2：转入低唤醒负向

- Valence：正向 -> 负向
- Arousal：高 -> 低到中低

### 阶段 3：负向强化

- Valence：维持负向
- Arousal：低 -> 高

### 阶段 4：恢复段

- Valence：负向 -> 中性附近
- Arousal：高 -> 低

### 为什么四阶段版更适合第一轮实验

1. 少一个正向缓和阶段，整体更短
2. 被试负担更低
3. 更容易在早期验证每一阶段是否真的被视频实现
4. 如果阶段 2 和阶段 3 的边界不清晰，调试成本更低

### 五阶段版和四阶段版的关系

- 四阶段版适合：
  - pilot
  - 素材筛选
  - prompt 映射调试
  - 评分流程测试

- 五阶段版适合：
  - 正式主实验
  - 比较轨迹控制质量
  - 比较个体化与通用刺激的阶段差异

## 六、推荐的实验实现方式

这套轨迹更适合使用：

- 分阶段视频片段串联

而不是：

- 一条完全连续、没有分段标记的超长视频

### 推荐做法

每个阶段单独对应一个短视频段：

- baseline：20 到 30 秒
- 其余阶段：15 到 35 秒

每段结束后立即采样：

- valence
- arousal
- intensity
- self-relevance
- liking

### 推荐理由

- 便于验证每一阶段是否真的达到了目标轨迹
- 便于分析哪一阶段最容易失败
- 便于后续做个体化重写

### 当前建议的正式组织方式

如果做正式实验，建议采用：

- `baseline + 五阶段`

如果做第一轮验证，建议采用：

- `baseline + 四阶段`

## 六点五、trial 数量与时长建议

为了把轨迹设计真正落到实验执行，当前建议直接固定两套版本：

### 方案 A：pilot 版

结构：

- 1 个条件
- `baseline + 四阶段`

总数：

- baseline 段：1
- 刺激 trial：4

单个刺激 trial 建议包括：

1. fixation：3 秒
2. 视频刺激：25 秒
3. 即时评分：12 秒
4. recovery：15 秒

单个 trial 约：

- `55 秒`

pilot 总时长约：

- baseline：30 秒
- 4 个 trial：220 秒
- 说明与练习、短休息：3 到 5 分钟

合计约：

- `7 到 9 分钟`

### 方案 B：正式主实验版

结构：

- 3 个条件
  - 通用视频
  - 问卷个体化视频
  - 问卷 + 样例反馈校准视频
- 每个条件 1 个 block
- 每个 block 采用 `baseline + 五阶段`

总数：

- baseline 段：3
- 刺激 trial：15

单个刺激 trial 建议包括：

1. fixation：3 秒
2. 视频刺激：25 秒
3. 即时评分：12 秒
4. recovery：15 秒

单个 trial 约：

- `55 秒`

单个 block 约：

- baseline：30 秒
- 5 个 trial：275 秒
- block 小休息：60 秒

即：

- `约 6 分钟`

整个正式主实验约：

- 3 个 block：18 分钟
- 说明与练习：5 分钟
- 条件切换说明：2 到 3 分钟
- 实验结束恢复：1 到 2 分钟

合计约：

- `25 到 30 分钟`

## 七、对子项目 01 的实验价值

这条五阶段轨迹的研究价值很高，因为它能帮助你比较：

1. 通用视频是否能稳定实现目标轨迹
2. 个体化视频是否更容易实现目标轨迹
3. 哪个阶段最依赖个体化信息

特别是：

- 阶段 3 的“低唤醒负向过渡”
- 阶段 5 的“恢复段”

很可能最依赖个体画像和自我相关线索。

## 八、推荐采集指标

### 主观指标

- valence
- arousal
- intensity
- self-relevance
- familiarity
- liking

### 生理指标

- EEG
- ECG / HR / HRV
- EDA

### 行为指标

- 继续观看意愿
- 回避意愿
- 再看意愿

## 九、当前结论

你的五阶段流程总体上是合理的，而且有研究潜力。

最值得保留的核心结构是：

1. 正向激活
2. 正向缓和
3. 低唤醒负向过渡
4. 负向高唤醒强化
5. 恢复段

但为了更符合文献和实验规律，建议：

1. 在五阶段前单独加入 neutral baseline
2. 把阶段 3 明确为低唤醒负向，而不是泛化负向
3. 把阶段 5 明确为恢复到中性附近，而不是强行完全归零
4. 每阶段后都做即时评分
5. 第一轮实验优先采用四阶段简化版，正式主实验再采用五阶段版
