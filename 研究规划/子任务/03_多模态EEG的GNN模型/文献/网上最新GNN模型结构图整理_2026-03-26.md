# 网上最新GNN模型结构图整理

## 日期

2026-03-26

## 用途

本文件不是泛泛罗列 GNN 论文，而是专门整理当前网上能直接看到、并且对本子任务有参考价值的 **GNN 类模型结构图来源**。

重点用途有三个：

- 帮你快速建立“最近主流 GNN 结构长什么样”的直觉
- 帮你判断哪些图适合借来参考自己的模型图
- 帮你把“通用 GNN 结构”与“EEG / 多模态 / cross-subject 结构”区分开

## 先看结论

如果你的目标是服务当前子任务 3，而不是系统学习整个图学习领域，那么最值得优先看的不是最花哨的图，而是下面这几类：

1. **Graph Transformer 总览图**
   用来建立通用架构视角
2. **GNNFormer 结构图**
   用来理解最近两年“图传播 + 变换解耦”的主流思路
3. **EmT / MVGT / FreqDGT 结构图**
   用来直接参考 EEG 情感识别里的图模型结构
4. **CLARGA 结构图**
   用来参考“多模态图融合怎么组织”
5. **ScaDyG / DistillHGNN 结构图**
   用来参考动态图和轻量学生模型这两条较新的结构线

## 一、总览型结构图

### 1. Graph Transformers: A Survey

- 时间：2024-07-13
- 类型：综述
- 链接：[arXiv](https://arxiv.org/abs/2407.09777)
- 价值：
  这篇更适合拿来建立总览视角。它不是单一模型图，而是把 graph transformer 的设计空间、深度、可扩展性和预训练路线做了系统归纳。
- 适合你看的点：
  - 先建立“Graph Transformer 不等于一个固定结构”的认识
  - 帮你区分 `graph inductive bias`、`attention design`、`scalability` 这些设计维度
- 对当前任务的启发：
  你后面画自己的模型图时，可以把“频段建模、空间图、跨模态融合、时间模块”拆成几个明确模块，而不是画成一整块黑箱

### 2. A Survey on Structure-Preserving Graph Transformers

- 时间：2024-01-29
- 类型：综述
- 链接：[arXiv](https://arxiv.org/abs/2401.16176)
- 价值：
  这篇更适合看“图结构信息到底是怎么被保留下来的”。对你这种要自己定义节点和边的人尤其重要。
- 适合你看的点：
  - 节点特征调制
  - 上下文节点采样
  - 图重写
  - Transformer 结构改造
- 对当前任务的启发：
  你后面如果做 EEG + ECG + RESP + EDA，不一定非要直接拼一个大图，也可以从“结构保留策略”角度去设计跨模态连接

## 二、通用前沿 GNN / Graph Transformer 结构图

### 3. GNNFormer

- 论文：Rethinking Graph Transformer Architecture Design for Node Classification
- 时间：2024-10-15
- 链接：[arXiv](https://arxiv.org/abs/2410.11189)
- 结构图位置：
  - `Figure 3`
  - 在 ar5iv HTML 中明确写到 `Figure 3: Illustration of graph transformer architectures.`
- 结构核心：
  - 把原始 GT 的 `MHA` 替换为可堆叠的 `PT-block`
  - 把消息传递拆成 `Propagation / Transformation`
  - 优化 FFN 和残差连接
- 适合你借鉴的点：
  - 为什么最近很多图模型都在做“传播和变换解耦”
  - 为什么不一定要把 Transformer 当成全局注意力去硬套
- 对当前任务的直接价值：
  你后面如果发现多模态图太复杂，可以把图传播层和时序建模层拆开，而不是全部交给一个大模块
- 参考来源：
  [arXiv 摘要页](https://arxiv.org/abs/2410.11189)
  [ar5iv HTML](https://ar5iv.org/html/2410.11189v1)

### 4. ScaDyG

- 论文：ScaDyG: A New Paradigm for Large-scale Dynamic Graph Learning
- 时间：
  - arXiv 提交：2025-01-27
  - PubMed / TNNLS online ahead of print：2026-01-12
- 链接：
  [arXiv](https://arxiv.org/abs/2501.16002)
  [PubMed](https://pubmed.ncbi.nlm.nih.gov/41525529/)
- 结构核心：
  - Time-aware Topology Reformulation
  - Dynamic Temporal Encoding
  - Hypernetwork-driven Message Aggregation
- 适合你借鉴的点：
  - 如果以后想从静态 EEG 图升级到动态图，这是很值得参考的一种现代写法
  - 它强调先做可扩展的时间感知图传播，再做自适应聚合
- 对当前任务的直接价值：
  你现在第一版可以先不做动态图，但这张结构图很适合作为后续“二阶段升级路线”的参考图

### 5. DistillHGNN

- 论文：DistillHGNN
- 时间：ICLR 2025
- 链接：[ICLR 2025 PDF](https://proceedings.iclr.cc/paper_files/paper/2025/file/5aded482dfc82e6bbb822400cf94b038-Paper-Conference.pdf)
- 结构图位置：
  - `Figure 1`
- 结构核心：
  - 教师模型：HGNN + MLP
  - 学生模型：TinyGCN + MLP
  - 通过软标签和对比学习做知识蒸馏
- 适合你借鉴的点：
  - 大模型 / 高阶图模型并不是唯一终点
  - 可以先做强教师，再蒸馏成轻量结构
- 对当前任务的直接价值：
  如果你后面想做可部署版本，或者想做实时 affective BCI，这个结构思路非常值得保留

## 三、与你当前任务最相关的 EEG 图模型结构图

### 6. EmT

- 论文：EmT: A Novel Transformer for Generalized Cross-subject EEG Emotion Recognition
- 时间：
  - 初始提交：2024-06-26
  - IEEE TNNLS 相关版本：2025
- 链接：[arXiv](https://arxiv.org/abs/2406.18345)
- 结构核心：
  - Temporal Graph Construction
  - Residual Multi-view Pyramid GCN
  - Temporal Contextual Transformer
  - Task-Specific Output
- 为什么值得看：
  这是把“时序图构造 + 图表示学习 + Transformer 时间上下文建模”连起来的一条完整路线。
- 对当前任务的直接价值：
  你当前的多模态方案也可以采用类似分层写法：
  - 先构图
  - 再图表示
  - 再时间聚合
  - 最后分类

### 7. MVGT

- 论文：MVGT: A Multi-view Graph Transformer Based on Spatial Relations for EEG Emotion Recognition
- 时间：
  - 初始提交：2024-07-03
  - 最近修订：2026-03-13
- 链接：[arXiv](https://arxiv.org/abs/2407.03131)
- 结构核心：
  - 同时整合时间域、频域和空间编码
  - 用 multi-view graph transformer 融合多域 EEG 信息
- 为什么值得看：
  这篇和你当前任务的关联非常强，因为它天然就是“多视角图建模”。
- 对当前任务的直接价值：
  你虽然现在是多模态而不是单 EEG 多视角，但可以把“多视角”换成“多模态”，结构组织方式仍然可以借鉴

### 8. FreqDGT

- 论文：FreqDGT: Frequency-Adaptive Dynamic Graph Networks with Transformer for Cross-subject EEG Emotion Recognition
- 时间：
  - 初始提交：2025-06-28
  - 最近修订：2025-08-19
- 链接：[arXiv](https://arxiv.org/abs/2506.22807)
- 结构核心：
  - Frequency-Adaptive Processing
  - Adaptive Dynamic Graph Learning
  - Multi-scale Temporal Disentanglement Network
  - 面向 cross-subject 的对抗式解耦
- 为什么值得看：
  这是最近非常贴近你当前兴趣点的一张结构图，因为它把 `频段自适应 + 动态图 + 时间建模 + 跨被试稳健性` 放在同一个框架里。
- 对当前任务的直接价值：
  即使你先不做动态图，也可以借它的“分频段处理 + 层次时间模块”结构

### 9. MSGM

- 论文：MSGM: A Multi-Scale Spatiotemporal Graph Mamba for EEG Emotion Recognition
- 时间：2025-07-21
- 链接：[arXiv](https://arxiv.org/abs/2507.15914)
- 结构核心：
  - 多窗口时间切分
  - Global-local 双图建模
  - 多层 GCN
  - Mamba 融合时空交互
- 为什么值得看：
  这篇代表了一种较新的路线，即图模型不一定非要配 Transformer，也可以配状态空间模型。
- 对当前任务的直接价值：
  如果你后面发现 Transformer 太重，Mamba 类时间模块可以作为替代参考

## 四、多模态图融合结构图

### 10. CLARGA

- 论文：CLARGA: Multimodal Graph Representation Learning over Arbitrary Sets of Modalities
- 时间：2025-12-10
- 链接：[arXiv](https://arxiv.org/abs/2512.11901)
- 结构核心：
  - 对每个样本动态构建模态关系图
  - 用 multi-head GAT 做模态间消息传递
  - 可处理任意数量模态
  - 支持缺失模态
- 为什么值得看：
  这类图对你的子任务 3 非常有启发，因为你当前模态已经不是单一 EEG，而是 EEG + ECG + RESP + EDA，未来还可能继续加眼动和 EGG。
- 对当前任务的直接价值：
  这是目前最值得你参考的“跨模态关系图”思路之一
- 注意：
  这篇不是 EEG 专题论文，而是更通用的多模态图融合框架，因此更适合借结构，不适合直接照搬实验设定

## 六、对当前任务的实际建议

综合这轮“结构图导向”的检索，当前最值得你借鉴的不是某一张单独的图，而是 3 个结构思想：

1. **分模块设计**
   先分清 `输入表示`、`图构造`、`图传播`、`时间建模`、`融合`、`输出`
2. **多视角 / 多模态分层融合**
   不要一开始就把所有模态压进一个大图里
3. **先静态图基线，再升级动态或跨被试增强**
   这和我们目前对子任务 3 的推进顺序一致
