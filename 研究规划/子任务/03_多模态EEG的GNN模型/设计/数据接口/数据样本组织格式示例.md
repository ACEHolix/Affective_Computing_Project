# 数据样本组织格式示例

## 目的

本文件用于把子任务 3 的数据组织方式具体化，方便后续：

- 做预处理导出
- 写 `Dataset`
- 对接模型输入

## 一、推荐样本单位

推荐一个样本定义为：

- 一个固定时间窗口

例如：

- 4 秒窗口

该窗口内同时包含：

- EEG
- ECG
- RESP
- EDA
- 标签

## 二、样本字段定义

每个样本建议包含以下字段：

```python
sample = {
    "sample_id": "sub01_trial03_win05",
    "subject_id": "sub01",
    "trial_id": "trial03",
    "window_id": 5,
    "label": 2,
    "x_eeg": ...,
    "x_phy": ...,
    "adj_eeg": ...,
    "adj_phy": ...,
    "adj_cross": ...,
}
```

## 三、各字段详细说明

## 1. `sample_id`

字符串类型。

作用：

- 保证样本唯一标识
- 便于追踪错误样本

示例：

```python
"sub01_trial03_win05"
```

## 2. `subject_id`

作用：

- 用于 cross-subject 划分

示例：

```python
"sub01"
```

## 3. `trial_id`

作用：

- 标识原始试次

## 4. `window_id`

作用：

- 标识窗口编号

## 5. `label`

第一版建议：

- 整数分类标签

例如：

```python
0  # negative
1  # neutral
2  # positive
```

如果后续做回归，可以改为：

```python
label = {
    "valence": 0.73,
    "arousal": 0.41
}
```

## 四、特征张量格式

## 1. `x_eeg`

定义：

- EEG 节点特征矩阵

形状：

```python
[N_eeg, D_eeg]
```

例如：

- `N_eeg = 32`
- `D_eeg = 5`

如果每个通道用 5 个频带功率作为特征，则：

```python
x_eeg.shape = [32, 5]
```

## 2. `x_phy`

定义：

- 外周模态节点特征矩阵

第一版建议：

- ECG 一个节点
- RESP 一个节点
- EDA 一个节点

形状：

```python
[3, D_phy]
```

例如：

- `D_phy = 4`

那么：

```python
x_phy.shape = [3, 4]
```

示意：

```python
x_phy = [
    [hr, rmssd, sdnn, lf_hf],        # ECG
    [resp_rate, amp_mean, amp_std, cycle_mean],  # RESP
    [tonic_mean, phasic_mean, scr_count, scr_amp] # EDA
]
```

## 五、邻接矩阵格式

## 1. `adj_eeg`

定义：

- EEG 通道图邻接矩阵

形状：

```python
[N_eeg, N_eeg]
```

示例：

```python
adj_eeg.shape = [32, 32]
```

## 2. `adj_phy`

定义：

- 外周模态图邻接矩阵

第一版中外周节点数为 3。

形状：

```python
[3, 3]
```

可先设为简单全连接：

```python
adj_phy = [
    [1, 1, 1],
    [1, 1, 1],
    [1, 1, 1]
]
```

## 3. `adj_cross`

定义：

- 跨模态图邻接矩阵

节点总数：

```python
N_all = N_eeg + 3
```

形状：

```python
[N_all, N_all]
```

第一版建议：

- 保留 EEG 内部边
- EEG 每个节点连接到 ECG/RESP/EDA 节点

## 六、推荐存储格式

## 方案 A：每个样本存为 `.pt`

适合 PyTorch。

例如：

```python
torch.save(sample, "sub01_trial03_win05.pt")
```

优点：

- 直接读取为 tensor
- 最方便对接训练

## 方案 B：整个数据集存成一个字典

例如：

```python
dataset = {
    "samples": [...],
    "meta": {...}
}
```

适合规模不大时快速实验。

## 七、批处理后的张量格式

训练时，一个 batch 推荐整理成：

```python
batch = {
    "x_eeg": [B, N_eeg, D_eeg],
    "x_phy": [B, 3, D_phy],
    "adj_eeg": [B, N_eeg, N_eeg],
    "adj_phy": [B, 3, 3],
    "adj_cross": [B, N_all, N_all],
    "label": [B]
}
```

## 八、最小样本示例

```python
sample = {
    "sample_id": "sub01_trial03_win05",
    "subject_id": "sub01",
    "trial_id": "trial03",
    "window_id": 5,
    "label": 2,
    "x_eeg": torch.randn(32, 5),
    "x_phy": torch.randn(3, 4),
    "adj_eeg": torch.eye(32),
    "adj_phy": torch.ones(3, 3),
    "adj_cross": torch.ones(35, 35),
}
```

## 九、当前最推荐的实现方式

第一版建议：

- 预处理后，把每个窗口导出为一个 `.pt` 文件
- 训练时由 `Dataset` 动态读取

原因：

- 最直接
- 易调试
- 便于后续换标签和换图构造方式
