## Recommended Scope

- Primary focus: EEG-based emotion recognition
- Application context: affective computing and brain-computer interfaces
- Method focus: machine learning and deep learning
- Study types: original research papers, supported by recent review papers
- Suggested time span for core analysis: 2020-2026
- Optional boundary: include multimodal work only when EEG remains the primary modality

## Notes For Writing

- Avoid claiming one model is better purely from headline accuracy across different datasets.
- Keep subject-dependent and subject-independent results separate.
- Use review papers to frame the field, but build the main analysis from original studies.
- Treat multimodal studies as a separate subsection if included.
