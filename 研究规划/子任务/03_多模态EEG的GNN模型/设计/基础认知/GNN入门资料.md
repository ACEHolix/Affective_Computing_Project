# GNN入门资料

## 这份资料的目的

这份资料不是为了系统讲完整个图神经网络领域，而是为了让你能够尽快理解：

- GNN 是什么
- 它和普通神经网络有什么不同
- 为什么它适合 EEG 和多模态生理信号
- 在你的任务里，图应该怎么想、模型应该怎么搭

如果你后面要做的是“适合分析多模态 EEG 数据的 GNN 类模型”，这份资料够你建立一个能开始做设计和读论文的基础框架。

## 一、先用一句话理解 GNN

**GNN 就是专门处理“图结构数据”的神经网络。**

这里的“图”不是画出来的图像，而是由：

- 节点
- 边

构成的关系结构。

例如：

- 社交网络里，人是节点，好友关系是边
- 脑电里，电极通道是节点，通道之间的连接关系是边

## 二、为什么普通神经网络不够

普通模型通常更擅长处理：

- 向量
- 序列
- 图像

例如：

- MLP 处理固定维向量
- LSTM 处理时间序列
- CNN 处理网格化图像

但 EEG 通道之间的关系并不是规则网格，更像一个“非规则连接网络”。  
这时如果还强行用普通 CNN，就会有一个问题：

- CNN 默认邻居关系是固定的、规则的
- 但 EEG 电极之间的关系是空间上的、功能上的、甚至会随任务变化

GNN 的意义就在于：

- 直接在“谁和谁有关系”这个结构上做学习

## 三、图的基本组成

在 GNN 里，你至少要明确 3 件事：

### 1. 节点是什么

在你的任务里，节点可以是：

- EEG 通道
- 脑区
- ECG / RESP / EDA 这些模态特征单元
- 眼动或 EGG 特征单元

### 2. 边是什么

边表示两个节点之间有某种关系。

比如：

- EEG 通道物理位置相近
- 两个通道功能连接强
- EEG 与 ECG 在某个时间窗口有协同变化
- EEG 与 EDA 在某类情绪下相关

### 3. 节点特征是什么

每个节点本身要有输入特征。

例如：

- EEG 节点的 PSD、DE、时频特征
- ECG 节点的 HRV 特征
- RESP 节点的呼吸频率、幅度
- EDA 节点的皮电水平和 phasic 成分

## 四、GNN 的核心思想

GNN 最核心的操作可以理解为：

**每个节点不断从自己的邻居那里“收集信息”，再更新自己的表示。**

简单地说：

1. 一个节点先看看和自己相连的是谁
2. 收集这些邻居的特征
3. 把邻居特征和自己的特征融合
4. 得到新的节点表示

经过多层以后，一个节点就不只是代表自己，而是逐渐带上周围关系的信息。

这就是为什么 GNN 特别适合“关系型数据”。

## 五、最常见的几类 GNN

## 1. GCN

全称：

- Graph Convolutional Network

你可以把它理解成：

- 图上的基础卷积网络

特点：

- 结构相对简单
- 很适合做基线
- 经常是第一版图模型

在 EEG 里常见用法：

- 把 EEG 通道当节点
- 用空间关系或功能连接建边
- 用图卷积聚合邻居信息

## 2. GAT

全称：

- Graph Attention Network

特点：

- 不同邻居的重要性不一样
- 模型会学习“该更关注谁”

在 EEG 里很适合：

- 找关键通道
- 找关键脑区连接
- 找不同模态之间更重要的连接

## 3. GraphSAGE

特点：

- 强调从邻居采样再聚合
- 更偏工程可扩展性

在你当前任务里不是第一优先，但理解为：

- 另一种常见的图特征聚合方式

## 4. GIN

全称：

- Graph Isomorphism Network

特点：

- 图结构判别能力比较强
- 常用于更强调结构表达能力的场景

如果你后面读到“Graph Isomorphism Network”，不用怕，它本质上还是在做图上的特征聚合，只是形式更强。

## 5. 动态图模型

特点：

- 图结构不是固定的
- 不同样本、不同时间点，边可以变化

它特别适合 EEG，因为：

- EEG 本来就是非平稳信号
- 情绪状态也是动态变化的

## 六、GNN 在 EEG 任务里为什么特别常见

因为 EEG 天然满足“图”的两个条件：

### 1. 节点天然存在

- 电极通道就是节点

### 2. 节点之间天然有关系

这些关系可以来自：

- 空间距离
- 功能连接
- 同步活动
- 频带耦合

所以用 GNN 处理 EEG 很自然。

相比之下：

- CNN 更偏规则网格
- LSTM 更偏纯时间序列
- GNN 更偏“带关系的脑网络”

## 七、为什么 GNN 对你的多模态任务也合适

你现在的模态是：

- EEG
- ECG
- RESP
- EDA

以后可能还有：

- 眼动
- EGG

这时问题就变成了：

- 不只是 EEG 内部通道之间有关系
- 不同模态之间也有关系

例如：

- EEG 和 ECG 可能共同反映情绪唤醒
- EEG 和 EDA 可能在高 arousal 情况下联动
- EEG 和 RESP 可能在压力、恐惧等状态下协同变化

这时 GNN 的优势就更明显，因为你可以：

- 先建 EEG 内部图
- 再建外周生理内部图
- 再建跨模态连接图

这比单纯把特征拼起来更有结构性。

## 八、你当前任务里，图可以怎么定义

这是最关键的问题。

## 方案 1：EEG 主图 + 外周特征附加

做法：

- EEG 通道作为主节点
- ECG / RESP / EDA 做成全局特征，后面再融合

优点：

- 最简单
- 容易先跑通

缺点：

- 没有真正发挥多模态图的优势

## 方案 2：多图融合

做法：

- EEG 一张图
- 外周生理一张图
- 跨模态再建一张图

优点：

- 结构清楚
- 非常适合你的当前阶段

缺点：

- 需要设计多图如何融合

## 方案 3：异构图

做法：

- 不同模态用不同类型节点
- 不同关系用不同类型边

优点：

- 最符合真实多模态结构

缺点：

- 建模复杂
- 对数据和实现要求更高

## 九、如何理解“边怎么建”

这也是初学者最容易卡住的地方。

边不一定只有一种来源。

常见做法有：

### 1. 按物理距离建边

适合 EEG。

例如：

- 相邻电极连边

### 2. 按统计相关性建边

例如：

- Pearson correlation
- coherence
- phase locking

### 3. 按经验规则建边

例如：

- 同一脑区内部强连接
- 特定模态之间建立默认连接

### 4. 按模型自动学习边

也就是：

- 邻接矩阵可学习

这种方式更灵活，但更复杂。

## 十、GNN 训练时通常输出什么

对你的任务来说，最常见的是：

### 1. 图级分类

输入一个样本的整张图，输出：

- 正/中/负
- 某几类情绪

### 2. 图级回归

输出：

- valence
- arousal

### 3. 跨被试识别

训练和测试来自不同被试，考察泛化能力。

## 十一、GNN 和你会看到的关键词之间是什么关系

你后面读论文时，经常会看到下面这些词：

### 1. Attention

意思：

- 对更重要的节点或边给更高权重

### 2. Dynamic Graph

意思：

- 图结构可以变

### 3. Heterogeneous Graph

意思：

- 节点和边不止一种类型

### 4. Cross-Subject

意思：

- 不同被试间泛化

### 5. Domain Adaptation

意思：

- 让模型尽量减少不同被试或不同场景带来的分布差异

你可以把这些看成是在基础 GNN 之上逐步加的“能力模块”。

## 十二、你现在最不需要担心的事

如果你刚接触 GNN，不要一开始就纠结这些问题：

- 要不要上最复杂的异构动态图
- 要不要把全部模态一次性放进去
- 要不要直接做最前沿模型

因为这会让你很容易陷入结构过重、训练困难、解释不清的问题。

## 十三、你现在最应该掌握的顺序

建议按这个顺序理解和实践：

1. 明白图的节点、边、节点特征是什么
2. 先理解静态 GCN
3. 再理解 GAT
4. 再看多图融合
5. 最后再考虑异构图、动态图和跨被试

## 十四、对你当前任务最推荐的学习路径

结合你的数据情况，我建议你按下面的路线学：

### 第一步

先理解：

- 单模态 EEG GCN 是怎么搭的

### 第二步

再理解：

- 多图融合为什么比简单拼接更有意义

### 第三步

再考虑：

- 如何把 ECG、RESP、EDA 加进来

### 第四步

最后再扩展：

- 眼动
- EGG
- cross-subject
- 模态可信度

## 十五、你当前最推荐的起步模型

如果你现在就要选一个最适合入门和后续扩展的路线，我建议：

**“EEG 图 + 外周生理图 + 跨模态连接图”的多图融合 GNN**

原因：

- 结构直观
- 容易解释
- 和你的数据最匹配
- 后面升级成异构图也自然
