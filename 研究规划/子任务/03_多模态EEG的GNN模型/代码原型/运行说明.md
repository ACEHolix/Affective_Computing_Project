# 运行说明

## 当前包含内容

这个原型代码目录目前包含：

- dummy sample 生成脚本
- 第一版模型骨架
- Dataset 接口
- 训练入口
- 预处理脚本骨架

## 运行前依赖

当前最少需要：

```bash
pip install -r requirements.txt
```

如果后续要切换到正式图网络实现，建议再安装：

```bash
pip install torch-geometric
```

## 最小可运行 demo

在 `原型代码` 目录下执行：

```bash
python scripts/make_dummy_sample.py
python src/train.py
```

如果一切正常，会先生成一个 dummy `.pt` 样本，然后输出若干轮训练 loss。

说明：

当前工作区环境里还没有安装 `torch`，所以我本地验证时运行被依赖缺失阻塞。代码结构已补齐，但要先安装依赖后才能实际跑通。

## 建议执行顺序

当依赖准备好后，建议按下面顺序执行：

```bash
python scripts/connect_monkey_reward.py
python scripts/make_raw_dataset_template.py
python src/preprocess.py
python src/export_dataset.py
python src/split_dataset.py
python scripts/make_dummy_sample.py
python src/train.py
```

说明：

- 如果你已经有真实数据，就不需要 `make_raw_dataset_template.py`
- 如果你已经导出了真实 `.pt` 样本，就不需要 `make_dummy_sample.py`

## 后续接入真实数据

建议流程：

1. 修改 `configs/preprocess.yaml`
2. 实现或替换 `src/preprocess.py` 中的数据读取部分
3. 运行预处理脚本导出 `.pt` 样本
4. 再运行训练脚本

## 对接 Monkey_reward

如果后续要接外部母仓库 `Monkey_reward`，建议先执行：

```bash
python scripts/connect_monkey_reward.py
bash scripts/try_enter_monkey_env.sh
```

说明：

- `connect_monkey_reward.py` 负责发现仓库、数据和输出路径，并导出清单
- `try_enter_monkey_env.sh` 负责按协作文档约定尝试进入容器环境
- 如果默认路径不对，可先设置：

```bash
export MONKEY_REPO=/your/path/to/Monkey_reward
export MONKEY_DATA="$MONKEY_REPO/Preprocessed Data"
export MONKEY_OUTPUT="$MONKEY_REPO/outputs"
```
