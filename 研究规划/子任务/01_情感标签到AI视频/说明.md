# 分任务 01：从情感标签到个体化情绪诱发视频的工作流系统

## 任务目标

建立一个研究方向工作区，专门研究如何把：

- 情感标签
- 情绪类别
- valence-arousal 维度
- 情绪轨迹
- 个体画像信息

转化为可被 AI 视频生成模型使用的控制信号，从而生成在情绪风格、节奏、视觉氛围或叙事内容上可控、并能更稳定诱发目标情绪的视频。

## 问题定义

当前核心问题不再只是“能不能生成视频”，而是：

1. 如何把情感状态结构化表示成生成控制条件
2. 如何把个体画像、自我相关线索和样例反馈映射到视频生成控制变量
3. 如何让生成视频不只是“看起来像某种情绪”，而是真正诱发目标情绪变化
4. 如何评估个体化视频是否优于通用视频
5. 如何形成一个稳定的端到端工作流系统

## 建议的系统工作流

1. 个体画像输入层
   - 人口统计与媒介经验
   - 内容偏好
   - 自我相关线索
   - 风险边界
   - 样例刺激反馈

2. 情绪目标输入层
   - 目标情绪类别
   - valence-arousal 目标点
   - 五阶段情绪轨迹
   - 目标诱发强度

3. 个体化映射层
   - 将个体画像映射为：
     - 场景主题优先级
     - 叙事母题优先级
     - 视觉风格参数
     - 音频与节奏参数
     - 黑名单与强度上限

4. 刺激组织层
   - 候选模板筛选
   - prompt / shot list 生成
   - 时间段级控制序列
   - 五阶段视频片段串联

5. 视频生成与编辑层
   - 文生视频模型
   - 视频编辑/重写模型
   - 风格一致性与时序一致性约束

6. 评价与闭环层
   - 主观 valence / arousal / intensity 评分
   - self-relevance / familiarity / liking 评分
   - 多模态情感识别回评估
   - 个体化策略更新

## 值得研究的创新点

- 个体画像到视频 prompt 的自动映射机制
- 连续情绪轨迹驱动的视频生成
- 通用刺激与个体化刺激的系统性对比
- 情感可控的视频编辑而不是从零生成
- 个体化视频的情绪诱发效果自动评估
- 后续与 EEG / 生理反馈闭环的扩展接口

## 关键技术问题

- 情感标签到视觉语义之间缺少标准映射
- 同一情感标签对应的视频表达可能高度多样
- 同一视频对不同人的诱发效果差异很大
- 自我相关线索和普通偏好如何统一建模仍不清楚
- 生成视频的时序一致性与情感一致性未必一致
- 如何评估“生成的视频是否真的诱发了目标情绪变化”是难点

## 当前建议的文献关注方向

- affective video generation
- emotion-conditioned generation
- text-to-video controllability
- personalized emotion elicitation
- self-relevant affective stimuli
- multimodal affective computing for media generation
- EEG / emotion recognition to content generation mapping

## 下一步建议

1. 以“个体化情绪诱发视频系统”为主线收束研究问题
2. 固化最小可行输入：
   - 内容偏好
   - 自我相关线索
   - 风险边界
   - 样例刺激反馈
3. 以五阶段 valence-arousal 轨迹作为第一版实验主线
4. 先做对照实验：
   - 通用视频
   - 基于问卷的个体化视频
   - 基于问卷加样例反馈校准的视频
5. 再决定后续是否扩展到：
   - EEG 驱动闭环系统
   - 生理反馈驱动的在线个体化系统
