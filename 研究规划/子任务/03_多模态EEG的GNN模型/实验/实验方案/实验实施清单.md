# 实验实施清单

## 目标

把当前子任务 3 从“模型设计”推进到“可执行实验流程”。

## 一、准备阶段

### 1. 明确任务标签

- 确定是二分类、三分类还是回归
- 确定标签来自：
  - 离散情绪
  - valence/arousal

### 2. 明确数据切分单位

- 以 trial 为单位
- 以时间窗口为单位
- 以 session 为单位

### 3. 明确评价设置

- subject-dependent
- subject-independent

第一版建议先：

- subject-dependent 跑通

第二版再：

- subject-independent

## 二、数据处理阶段

### EEG

- 滤波
- 去伪迹
- 分段
- 提取通道级特征

### ECG

- 提取 HR / HRV 等特征

### RESP

- 提取呼吸频率、振幅、周期特征

### EDA

- 提取 tonic / phasic 特征

### 对齐

- 确保 4 种模态按同一时间窗口对齐

## 三、输入构造阶段

### 需要准备的输入

- EEG 节点特征矩阵
- ECG 节点特征
- RESP 节点特征
- EDA 节点特征
- `A_eeg`
- `A_phy`
- `A_cross`
- 标签 `y`

## 四、baseline 阶段

先做 4 个 baseline：

1. EEG 单模态 MLP / CNN
2. EEG 单模态 GCN
3. 多模态特征拼接 + MLP
4. 多图融合 GNN

## 五、训练阶段

### 推荐第一版配置

- optimizer：Adam
- learning rate：`1e-3` 起步
- batch size：按显存和数据量调整
- early stopping：建议开启

### 推荐记录内容

- train loss
- val loss
- accuracy / F1
- confusion matrix

## 六、对比实验阶段

### 必做对比

1. 单模态 vs 多模态
2. 非图融合 vs 图融合
3. 不同边构造方式

### 建议做的消融

1. 去掉 ECG
2. 去掉 RESP
3. 去掉 EDA
4. 去掉跨模态边
5. 去掉外周模态图

## 七、结果分析阶段

### 需要回答的问题

1. 多模态是否显著优于单模态 EEG
2. 图融合是否优于简单特征拼接
3. 哪个外周模态贡献最大
4. 跨模态边是否真的有帮助

## 八、第二阶段升级

当第一版跑通后，再继续：

1. GCN -> GAT
2. 固定边 -> 可学习边
3. subject-dependent -> subject-independent
4. 加入眼动
5. 视情况加入 EGG

## 九、当前最小执行顺序

推荐严格按下面顺序执行：

1. 统一时间窗口
2. 提取四模态特征
3. 搭 EEG 单模态 GCN
4. 搭多模态拼接 baseline
5. 搭多图融合 GNN
6. 做消融
7. 分析结果

## 十、当前结论

只要按这份清单推进，子任务 3 已经具备开始第一轮实现和实验的条件。
