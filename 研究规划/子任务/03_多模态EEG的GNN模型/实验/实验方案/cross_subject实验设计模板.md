# cross-subject 实验设计模板

## 目的

本模板用于为子任务 3 设计一套专门的 `cross-subject` 实验方案。

这套实验的核心问题不是：

- 模型在同一被试上能否得到高准确率

而是：

- 模型能否在不同被试之间保持稳定泛化

## 一、实验目标

本实验建议回答以下问题：

1. 多模态 GNN 是否优于单模态 EEG GNN
2. 多模态图融合是否优于普通多模态特征拼接
3. 在跨被试条件下，哪些模态最有帮助
4. 跨模态边是否能提升泛化性能

## 二、实验任务定义

### 推荐第一版任务

- 情感分类任务

例如：

- 二分类
- 三分类

### 推荐原因

- 更适合先验证泛化能力
- 更适合和 baseline 对比

## 三、数据划分方案

## 方案 A：固定被试划分

### 示例

```text
train_subjects = [sub01, sub02, sub03, sub04, sub05, sub06, sub07]
val_subjects   = [sub08]
test_subjects  = [sub09, sub10]
```

### 推荐用途

- 第一版 cross-subject 实验

## 方案 B：留一被试法

### 做法

- 每次留 1 个被试做测试
- 剩余被试训练

### 推荐用途

- 第二阶段更稳健的 cross-subject 评估

## 当前建议

第一阶段先做：

- 固定被试划分

第二阶段再做：

- 留一被试法

## 四、候选模型组

推荐至少比较以下几组模型：

### 1. 单模态 baseline

- EEG 单模态 MLP / CNN
- EEG 单模态 GCN

### 2. 多模态非图 baseline

- EEG + ECG + RESP + EDA 特征拼接 + MLP

### 3. 多图融合主模型

- EEG 图 + 外周图 + 跨模态图

### 4. 可选增强模型

- 图注意力多模态模型
- 图模型 + 域适应

## 五、评价指标

### 分类任务建议指标

- Accuracy
- Macro F1
- Weighted F1
- Confusion Matrix

### 推荐重点

在 cross-subject 条件下，建议重点看：

- Macro F1

因为它更稳，不会被类别不平衡误导。

## 六、必做对比实验

## 1. 单模态 vs 多模态

问题：

- 多模态是否真的提升泛化

## 2. 非图融合 vs 图融合

问题：

- 图结构是否真的提供额外增益

## 3. 去掉跨模态边

问题：

- 跨模态连接是否真的有帮助

## 4. 模态消融

问题：

- 哪个模态最重要

建议至少做：

- 去掉 ECG
- 去掉 RESP
- 去掉 EDA

## 七、推荐消融实验

### 1. EEG 内部图构造方式

- 空间图
- 功能连接图

### 2. 跨模态边构造方式

- 全连接
- 稀疏连接
- 可学习边权

### 3. 图编码器选择

- GCN
- GAT

## 八、结果记录模板

建议每轮实验至少记录：

- 划分方式
- 被试集合
- 模型名称
- 模态组合
- 是否有跨模态边
- Accuracy
- Macro F1
- Weighted F1
- 备注

## 九、结果分析建议

cross-subject 实验的分析重点不应只是“谁最高”，而应重点回答：

1. 多模态是否稳定优于单模态
2. 图模型是否在跨被试下更稳
3. 哪些模态在跨被试场景下更有贡献
4. 跨模态图结构是否真的帮助了泛化

## 十、推荐实验顺序

### 第一阶段

1. 跑 EEG 单模态 GCN
2. 跑多模态拼接 baseline
3. 跑多图融合 GNN

### 第二阶段

4. 做模态消融
5. 做跨模态边消融
6. 做 GAT 替换

### 第三阶段

7. 加入 domain adaptation 或对比学习

## 十一、当前结论

对你当前的任务来说，cross-subject 实验最重要的意义不是“提高一点点分数”，而是让你的课题从：

- 一个能工作的多模态图模型

提升为：

- 一个更接近真实应用的可泛化多模态图模型

这一步会明显提升研究价值。
