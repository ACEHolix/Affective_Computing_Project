# 研究范围定义

## 当前工作焦点

- 基于 EEG 的情感识别
- affective computing 与 BCI 应用背景
- 机器学习、深度学习与结构化建模方法
- 能为后续研究选题与实验设计提供直接参考的文献

## 当前优先关注的问题

- cross-subject generalization
- graph neural networks
- transformer 与 attention
- 数据集与情绪诱发范式
- VR / 沉浸式刺激
- EEG-centered 多模态方法
- 预处理自动化与鲁棒性

## 仍需明确的范围选择

- 是否把多模态作为主线还是扩展方向
- 是否把 VR 作为重点专题还是趋势性补充
- 是否优先面向方法创新，还是面向场景数据集构建
- 后续最优先收敛到哪个研究方向
