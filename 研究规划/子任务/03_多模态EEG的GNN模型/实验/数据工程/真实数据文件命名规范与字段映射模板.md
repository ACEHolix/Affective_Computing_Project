# 真实数据文件命名规范与字段映射模板

## 目的

本说明用于把真实数据接入流程进一步标准化，解决两个问题：

1. 原始文件应该怎么命名
2. 各模态字段后续在代码里怎么映射

## 一、推荐目录结构

```text
raw/
  sub01/
    trial01/
      eeg.csv
      ecg.csv
      resp.csv
      eda.csv
      label.json
    trial02/
      ...
  sub02/
    ...
```

## 二、推荐命名规范

### 被试目录

```text
sub01
sub02
sub03
```

### trial 目录

```text
trial01
trial02
trial03
```

### 模态文件

```text
eeg.csv
ecg.csv
resp.csv
eda.csv
eye.csv
egg.csv
label.json
```

## 三、如果你的真实命名不是这样

你后续只需要修改：

- `原型代码/src/io_templates.py`

中的：

- `build_modalities_file_map`

这一个函数即可。

## 四、推荐字段映射

## 1. EEG

推荐最少包含：

- `timestamp`
- 每个通道一列

示例：

```text
timestamp,Fp1,Fp2,F3,F4,C3,C4,...
0.000,0.12,0.10,...
0.004,0.15,0.09,...
```

## 2. ECG

示例：

```text
timestamp,ecg
0.000,0.03
0.004,0.05
```

## 3. RESP

示例：

```text
timestamp,resp
0.000,0.81
0.004,0.79
```

## 4. EDA

示例：

```text
timestamp,eda
0.000,3.42
0.004,3.43
```

## 5. 眼动

如果未来加入，推荐字段：

```text
timestamp,gaze_x,gaze_y,pupil_left,pupil_right
```

## 6. EGG

如果未来加入，推荐字段：

```text
timestamp,egg
```

## 五、标签文件字段

推荐与当前模板保持一致：

- `subject_id`
- `trial_id`
- `window_labels`

其中每个窗口内包含：

- `window_id`
- `start_time`
- `end_time`
- `class_label`
- `class_name`
- `valence`
- `arousal`

## 六、代码映射位置

当前代码中，字段映射主要对应：

### 1. `src/io_templates.py`

负责：

- 文件路径映射

### 2. `src/export_dataset.py`

负责：

- 标签读取
- 原始模态载入入口

### 3. `src/preprocess.py`

负责：

- 具体字段如何转成特征

## 七、当前推荐做法

如果你后续准备接真实数据，建议先做这几件事：

1. 先把真实文件重命名成统一规范
2. 如果不能重命名，再改 `io_templates.py`
3. 先保证四模态时间戳格式统一
4. 再进入预处理与导出

## 八、当前结论

越早统一文件命名和字段格式，后续接代码时越省事。  
对于当前原型工程来说，最重要的是：

- 路径规则统一
- 时间戳字段统一
- 标签文件结构统一
