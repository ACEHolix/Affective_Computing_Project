# 真实数据读取与导出脚本模板说明

## 当前新增脚本

已经为子任务 3 新增了一套不依赖真实环境细节的读取与导出脚本模板：

- `原型代码/src/io_templates.py`
- `原型代码/src/export_dataset.py`
- `原型代码/scripts/make_raw_dataset_template.py`
- `原型代码/data/README.md`

## 这套模板解决什么问题

它解决的是“真实数据怎么进入模型工程”这个问题。

目前已经明确了：

1. 原始数据目录怎么组织
2. 每个被试、每个 trial 怎么遍历
3. 每种模态文件路径怎么映射
4. 标签怎么读取
5. 预处理后样本怎么导出成 `.pt`

## 当前脚本分工

### 1. `io_templates.py`

作用：

- 扫描被试目录
- 扫描 trial 目录
- 生成每个 trial 的模态文件映射

### 2. `export_dataset.py`

作用：

- 读取 `raw/`
- 调用预处理入口
- 构造样本
- 导出到 `processed/`

### 3. `make_raw_dataset_template.py`

作用：

- 自动生成一套最小原始目录模板

方便你后续按同样结构替换成真实数据。

## 当前推荐使用顺序

1. 先运行 `make_raw_dataset_template.py`
2. 按模板替换成真实数据文件
3. 修改 `io_templates.py` 的文件命名规则
4. 修改 `export_dataset.py` 的标签读取规则
5. 修改 `preprocess.py` 的真实预处理逻辑
6. 运行导出脚本生成 `.pt` 样本
7. 再进入训练

## 当前限制

这套模板已经把工程接口搭好了，但还没有绑定你的真实数据格式。

也就是说，现在最需要你后续补充的是：

- 真实文件命名规则
- 真实标签格式
- 真实采样率
- 真实预处理逻辑

这一步完成后，子任务 3 已经具备：

- 数据目录模板
- 数据读取模板
- 样本导出模板
- 模型训练入口

后续真正的实现工作，已经可以围绕这些接口展开。
