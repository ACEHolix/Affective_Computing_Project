# 文献纳入与排除规则

## 目的

本规则用于保证当前工作区中的文献，能够真实服务于：

- 研究方向判断
- 题目收敛
- 实验设计
- 摘要和开题准备

## 纳入标准

- 英文文献
- 与 EEG 情感识别直接相关
- 与下列主题至少有一个强相关：
  - cross-subject generalization
  - GNN / transformer / attention
  - 数据集或情绪诱发范式
  - VR / 沉浸式刺激
  - 多模态 EEG-centered 情感识别
  - 预处理、鲁棒性或部署
- 方法、实验设置或数据集信息足够明确

## 排除标准

- 与 EEG 无直接关系
- 只涉及泛泛情感计算而不落到 EEG 或相关实验设计
- 只讲理论概念但缺少方法或实验细节
- 重复记录
- 低相关或无法支撑后续研究决策的文献
