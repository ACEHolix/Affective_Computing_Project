# 候选GNN模型方案对比表

## 说明

本表面向“子任务 03：适合分析多模态EEG数据的GNN类模型”，用于比较当前最值得考虑的几种模型构造路线。

这里的重点不是追求模型数量，而是帮助后续快速做决策：

- 先做哪个模型最稳
- 哪个模型更适合当前数据
- 哪个模型更适合后续扩展眼动和 EGG
- 哪个模型更适合把 cross-subject 也纳入

## 对比表

| 模型名称 | 节点定义 | 边定义 | 是否支持多模态 | 是否支持跨被试 | 优点 | 风险 | 推荐优先级 |
|---|---|---|---|---|---|---|---|
| 单模态 EEG 静态 GCN 基线 | EEG 通道节点 | 电极空间邻接或功能连接 | 否 | 可扩展但默认较弱 | 结构简单，易实现，适合建立图模型基线 | 只能处理 EEG，无法体现多模态优势 | 中 |
| EEG 图 + 外周特征普通融合 | EEG 通道节点；ECG/RESP/EDA 作为全局特征 | EEG 内部图；外周特征不显式建图 | 部分支持 | 可扩展但不强 | 最容易起步，训练稳定，适合先验证多模态是否有增益 | 外周模态关系未被图化，创新性有限 | 中 |
| 多图融合 GNN | EEG 图节点 + 外周模态子图节点 | EEG 内部图、外周内部图、跨模态连接图 | 是 | 可支持 | 结构清晰，兼顾可解释性与扩展性，最适合当前模态组合 | 多图融合方式需要仔细设计，否则可能冗余 | 高 |
| 图注意力多模态模型 | EEG 节点 + 外周模态节点 | 静态图或可学习图，带注意力权重 | 是 | 可支持 | 能学习关键通道、关键模态和关键连接，可解释性较好 | 参数变多，更容易过拟合 | 高 |
| 动态多模态图模型 | EEG 节点 + 外周模态节点 | 邻接矩阵随样本或时间动态变化 | 是 | 强支持 | 更适合非平稳情绪信号和样本间差异，适合复杂时序建模 | 训练复杂，调参难，解释难度更高 | 中高 |
| 时空图模型 | EEG 节点 + 外周模态节点或时间片段节点 | 空间图 + 时间依赖边 | 是 | 可支持 | 同时处理空间关系和时间动态，适合 EEG 时序片段分析 | 结构偏重，计算成本较高 | 中高 |
| 异构图 GNN | 不同模态作为不同类型节点 | 不同模态内边 + 跨模态异构边 | 是 | 强支持 | 最贴近真实多模态结构，后续加眼动和 EGG 最自然 | 设计与实现复杂，对数据量和工程能力要求高 | 中高 |
| 模态可信度驱动图模型 | EEG 节点 + 外周模态节点 | 基础图 + 质量/可信度调节边权 | 是 | 强支持 | 适合真实采集环境，对噪声和模态不稳定性更鲁棒 | 需要额外质量估计模块，系统复杂度更高 | 中高 |
| 图模型 + 域适应 | EEG 或多模态节点 | 基础图结构 + 域对齐机制 | 是 | 是 | 直接针对跨被试泛化，研究价值高 | 需要严格实验协议和更多对比基线 | 高 |
| 图模型 + 对比学习 | EEG 或多模态节点 | 基础图结构 + 对比表示学习 | 是 | 是 | 适合提升泛化和鲁棒表示，容易形成较强方法创新 | 训练策略更复杂，容易增加实验难度 | 中高 |

## 当前最推荐的 3 条路线

### 1. 多图融合 GNN

推荐原因：

- 和你当前 `EEG + ECG + RESP + EDA` 最匹配
- 比简单拼接更有研究意义
- 比异构图更容易先做出来
- 后续可自然扩展到眼动和 EGG

### 2. 图注意力多模态模型

推荐原因：

- 比普通多图融合更进一步
- 更适合分析关键模态和关键连接
- 对解释“哪个模态在什么情绪下更重要”很有帮助

### 3. 图模型 + 域适应

推荐原因：

- 如果你希望课题更强，可以直接把 cross-subject 纳入
- 与当前领域热点更一致
- 容易和已有 GNN 情感识别文献形成衔接

## 当前最稳的研究推进顺序

建议不要一开始就上最复杂模型，而是按下面顺序推进：

1. 单模态 EEG GCN 基线
2. EEG 图 + 外周特征普通融合
3. 多图融合 GNN
4. 图注意力多模态模型
5. 再根据结果决定是否升级为：
   - 异构图
   - 动态图
   - 域适应
   - 模态可信度驱动图模型

## 如果现在就只能选一个主线

如果你现在必须只选一个最适合开始做的主线，我推荐：

**多图融合 GNN**

原因：

- 工程实现难度适中
- 和你的当前模态最匹配
- 可解释性较好
- 后续扩展空间足够大
