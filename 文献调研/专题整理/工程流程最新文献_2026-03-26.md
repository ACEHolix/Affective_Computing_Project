# EEG情感识别工程工作流分流程最新文献

## 说明

本文件按 EEG 情感识别工程中的典型工作流拆分文献，而不是按模型类别拆分。目的是帮助后续写综述时，直接从“工程流程”视角组织相关工作。

本轮优先关注近两年，时间窗口以 2024-2026 为主。

## 一、数据采集与情绪诱发

这一流程关注：

- 数据集建设
- 情绪诱发范式设计
- 单模态或多模态采集方案
- 更真实、更复杂的实验场景

### 代表文献

1. [EEG Dataset for the Recognition of Different Emotions Induced in Voice-User Interaction](https://pubmed.ncbi.nlm.nih.gov/39362909/)
   - 2024, Scientific Data
   - 提供面向语音交互场景的 EEG 情绪数据集
   - 相比传统视频/图片刺激，更贴近交互式应用场景

2. [Multimodal Emotion Recognition Based on EEG and EOG Signals Evoked by the Video-Odor Stimuli](https://pubmed.ncbi.nlm.nih.gov/39255190)
   - 2024, IEEE Transactions on Neural Systems and Rehabilitation Engineering
   - 把视频与气味刺激结合起来，说明当前情绪诱发范式正在从单一刺激走向多感官刺激

3. [An Enhanced Valence-Arousal Multimodal Emotion Dataset for Emotion Recognition](https://pubmed.ncbi.nlm.nih.gov/41397985/)
   - 2025, Scientific Data
   - 提供增强版 valence-arousal 多模态数据集，包含 EEG 在内的多种生理信号
   - 对后续讨论标签建模和个体差异很有价值

### 当前进展判断

- 数据采集正从经典公开数据集扩展到更具体的应用场景
- 情绪诱发方式从单一视觉/听觉刺激向多感官融合发展
- 多模态数据集越来越强调个体差异建模

## 二、预处理与伪迹去除

这一流程关注：

- 去伪迹
- 坏导联修复
- ICA / PCA / 自动化清洗
- 深度学习去噪

### 代表文献

1. [Protocol for semi-automatic EEG preprocessing incorporating independent component analysis and principal component analysis](https://pubmed.ncbi.nlm.nih.gov/40053447/)
   - 2025, STAR Protocols
   - 给出较规范的半自动 EEG 预处理流程
   - 对综述中写“标准预处理工作流”很有帮助

2. [A novel EEG artifact removal algorithm based on an advanced attention mechanism](https://pubmed.ncbi.nlm.nih.gov/40461599/)
   - 2025, Scientific Reports
   - 用注意力机制做 EEG 伪迹去除，代表预处理阶段开始引入深度学习重建思路

3. [AnEEG: leveraging deep learning for effective artifact removal in EEG data](https://www.nature.com/articles/s41598-024-75091-z)
   - 2024, Scientific Reports
   - 深度学习驱动的 EEG 去伪迹方法
   - 说明自动化预处理正在成为独立热点

### 当前进展判断

- 预处理不再只是传统信号处理步骤，正在被“自动化”和“学习式去噪”重新定义
- 未来综述里可以把预处理单独作为一个值得强调的趋势，而不是只在方法前简单带过

## 三、特征提取与表示学习

这一流程关注：

- 差分熵、功率谱、时频特征
- 自动分段
- 空间-时间联合表示
- 手工特征与自动表示的结合

### 代表文献

1. [An automated extraction of spectral-temporal and spatial-temporal features of EEG for emotion detection](https://pubmed.ncbi.nlm.nih.gov/40751855/)
   - 2025, Brain Informatics
   - 强调频谱-时间和空间-时间特征的自动提取
   - 适合支撑“从手工特征到自动表示”的过渡分析

2. [EEG emotion recognition based on data-driven signal auto-segmentation and feature fusion](https://pubmed.ncbi.nlm.nih.gov/38885847/)
   - 2024, Journal of Affective Disorders
   - 引入数据驱动的自动分段与特征融合
   - 很适合在综述中讨论“片段选择标准不统一”的问题

3. [EEG emotion recognition based on differential entropy feature matrix through 2D-CNN-LSTM network](https://link.springer.com/article/10.1186/s13634-024-01146-y)
   - 2024, EURASIP Journal on Advances in Signal Processing
   - 以差分熵矩阵作为中间表示，连接传统特征与深度模型

4. [A comparative analysis of emotion recognition from EEG signals using temporal features and hyperparameter-tuned machine learning techniques](https://pubmed.ncbi.nlm.nih.gov/40687354/)
   - 2025, MethodsX
   - 更偏传统机器学习基线
   - 有助于后续补“传统方法仍有价值”的论证

### 当前进展判断

- 特征工程正在从“固定手工特征”走向“自动分段 + 自动表示”
- 差分熵等传统特征并没有消失，而是在很多新方法中转化为深度模型输入

## 四、模型训练与情感识别

这一流程关注：

- CNN / RNN / Transformer
- 图神经网络
- 注意力机制
- 端到端分类模型

### 代表文献

1. [EmT: A Novel Transformer for Generalized Cross-Subject EEG Emotion Recognition](https://pubmed.ncbi.nlm.nih.gov/40208757/)
   - 2025, IEEE Transactions on Neural Networks and Learning Systems
   - 代表 Transformer 在 EEG 情感识别中的最新进展

2. [A temporal-spectral graph convolutional neural network model for EEG emotion recognition within and across subjects](https://pubmed.ncbi.nlm.nih.gov/39692964/)
   - 2024, Brain Informatics
   - 代表时间、频率、空间联合建模的图网络方向

3. [Attention-Based Temporal Graph Representation Learning for EEG-Based Emotion Recognition](https://pubmed.ncbi.nlm.nih.gov/38696290/)
   - 2024, IEEE Journal of Biomedical and Health Informatics
   - 图表示学习与时序注意力结合

4. [EEG-based emotion recognition using graph convolutional neural network with dual attention mechanism](https://pubmed.ncbi.nlm.nih.gov/39099770/)
   - 2024, Frontiers in Computational Neuroscience
   - 强调脑区和频带的重要性解释

5. [Emotion recognition using multi-scale EEG features through graph convolutional attention network](https://pubmed.ncbi.nlm.nih.gov/39742538/)
   - 2025, Neural Networks
   - 多尺度特征与图注意力结合

### 当前进展判断

- 图网络和注意力机制仍是模型层面的主线
- Transformer 已经从“尝试性使用”进入“高价值代表方法”阶段
- 模型创新越来越强调结构先验和可解释线索，而不只是提高准确率

## 五、泛化评估、跨被试与实时部署

这一流程关注：

- cross-subject evaluation
- subject-independent setting
- ensemble / domain adaptation
- real-time emotion recognition

### 代表文献

1. [Evolutionary Ensemble Learning for EEG-Based Cross-Subject Emotion Recognition](https://pubmed.ncbi.nlm.nih.gov/38954558/)
   - 2024, IEEE Journal of Biomedical and Health Informatics
   - 代表跨被试集成学习方向

2. [Cross-subject affective analysis based on dynamic brain functional networks](https://pubmed.ncbi.nlm.nih.gov/40297263/)
   - 2025, Frontiers in Human Neuroscience
   - 代表动态脑网络视角下的跨被试分析

3. [Enhancing cross-subject emotion recognition precision through unimodal EEG: a novel emotion preceptor model](https://pubmed.ncbi.nlm.nih.gov/39692977/)
   - 2024, Brain Informatics
   - 说明单模态 EEG 下的泛化能力提升仍是热门问题

4. [Real-time EEG-based emotion recognition for neurohumanities: perspectives from principal component analysis and tree-based algorithms](https://pubmed.ncbi.nlm.nih.gov/38545515/)
   - 2024, Frontiers in Human Neuroscience
   - 虽然方法相对传统，但直接对应实时部署场景

### 当前进展判断

- 评价重点正在从被试内高精度转向跨被试泛化
- 实时识别和可部署性仍然不是主流，但已经开始形成单独子方向
- 如果你的综述想体现新意，“泛化与部署”很适合作为重点章节

## 六、多模态融合流程

如果你的综述保留 EEG 主导的多模态子章节，这部分也值得单独列出。

### 代表文献

1. [Cross-modal credibility modelling for EEG-based multimodal emotion recognition](https://pubmed.ncbi.nlm.nih.gov/38565099/)
   - 2024, Journal of Neural Engineering
   - 重点讨论模态可信度和融合可靠性

2. [EEG-fNIRS-Based Emotion Recognition Using Graph Convolution and Capsule Attention Network](https://pubmed.ncbi.nlm.nih.gov/39199511/)
   - 2024, Brain Sciences
   - EEG 与 fNIRS 融合，代表脑信号多模态方向

3. [Multimodal Emotion Recognition Based on EEG and EOG Signals Evoked by the Video-Odor Stimuli](https://pubmed.ncbi.nlm.nih.gov/39255190)
   - 2024, IEEE Transactions on Neural Systems and Rehabilitation Engineering
   - 数据采集与多模态建模是联动发展的

### 当前进展判断

- 多模态研究正在从“简单拼接”转向“可信度建模”和“跨模态一致性”
- 如果纳入综述，建议明确限定为“EEG-centered multimodal emotion recognition”

## 总体结论

从工程工作流视角看，当前 EEG 情感识别的最新进展可以概括为：

1. 数据采集更真实，情绪诱发更复杂
2. 预处理更自动化，去伪迹开始深度学习化
3. 特征表示从手工特征走向自动提取与混合表示
4. 模型层面以图网络、注意力、Transformer 为主线
5. 评价重点正从被试内性能转向跨被试泛化
6. 多模态融合开始强调“可信度”和“场景真实性”

## 对综述写作的建议

如果后续按工程工作流来写方法综述，一个较稳的组织方式是：

1. 数据采集与情绪诱发
2. 预处理与去伪迹
3. 特征提取与表示学习
4. 模型训练与识别
5. 泛化评估与实时部署
6. 可选的多模态扩展

这种写法会比单纯按模型类别罗列更有“系统工程”视角。
