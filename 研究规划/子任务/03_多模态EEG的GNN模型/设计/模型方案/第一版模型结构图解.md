# 第一版模型结构图解

## 目标

把当前推荐的第一版模型落成一个足够具体的结构草案，便于后续：

- 开始写代码
- 和导师或合作方讨论
- 对照 baseline 设计实验

当前推荐主线仍然是：

**多图融合 GNN**

## 一、总体结构

```text
输入样本

├─ EEG 多通道窗口信号
├─ ECG 窗口信号
```

## 二、第一版推荐结构

## 1. 输入层

一个样本对应一个固定长度时间窗口。

推荐第一版：

- EEG：`N` 个通道
- ECG：1 个模态节点
- RESP：1 个模态节点
- EDA：1 个模态节点

## 2. 特征层

### EEG

每个通道提取一个特征向量，例如：

- band power
- DE
- PSD

得到：

- `X_eeg ∈ R^(N × d_eeg)`

### 外周模态

每个模态提取一个窗口级特征向量：

- `x_ecg ∈ R^(d_ecg)`
- `x_resp ∈ R^(d_resp)`
- `x_eda ∈ R^(d_eda)`

然后统一映射到同一维度：

- `d_model`

## 3. 图构建层

### 图 A：EEG 通道图

- 节点：EEG 通道
- 边：空间邻近边
- 邻接矩阵：`A_eeg`

### 图 B：外周模态图

- 节点：ECG、RESP、EDA
- 边：三者两两连接或按经验稀疏连接
- 邻接矩阵：`A_phy`

### 图 C：跨模态图

- 节点：EEG 通道 + ECG/RESP/EDA
- 边：
  - EEG 内部边保留
  - EEG 到各外周模态节点全连接
- 邻接矩阵：`A_cross`

## 4. 编码层

### EEG 编码器

推荐第一版：

- `GCN -> ReLU -> GCN`

输出：

- `H_eeg`

### 外周模态编码器

推荐第一版：

- `GCN -> ReLU`

输出：

- `H_phy`

### 跨模态融合

第一版最稳做法：

- 直接把 EEG 表示和外周表示投影到同一维度
- 在跨模态图上再过一层图卷积

输出：

- `H_fused`

## 5. 读出层

把节点级表示转成样本级表示。

推荐第一版：

- mean pooling
  或
- attention pooling

得到：

- `z ∈ R^(d_out)`

## 6. 任务头

### 分类任务

- `Linear -> Softmax`

### 回归任务

- `Linear -> Regression`

第一版建议先做分类任务。

## 三、第一版推荐网络深度

为了降低风险，第一版不建议太深。

推荐：

- EEG 编码器：2 层
- 外周图编码器：1 层
- 跨模态融合层：1 层
- 输出头：1 到 2 层 MLP

## 四、第一版推荐训练目标

如果先做分类：

- Cross Entropy Loss

如果后续做类别不平衡处理，可加入：

- weighted cross entropy
- focal loss

## 五、伪代码

```python
def model(eeg_features, ecg_feat, resp_feat, eda_feat,
          A_eeg, A_phy, A_cross):
    # 1. EEG node encoding
    H_eeg = GCN1(eeg_features, A_eeg)
    H_eeg = relu(H_eeg)
    H_eeg = GCN2(H_eeg, A_eeg)

    # 2. Peripheral node encoding
    X_phy = stack([ecg_feat, resp_feat, eda_feat])
    H_phy = GCN_phy(X_phy, A_phy)
    H_phy = relu(H_phy)

    # 3. Cross-modal fusion graph
    X_cross = concat_nodes(H_eeg, H_phy)
    H_cross = GCN_cross(X_cross, A_cross)
    H_cross = relu(H_cross)

    # 4. Graph readout
    z = mean_pool(H_cross)

    # 5. Prediction
    y = classifier(z)
    return y
```

## 六、后续升级点

当前第一版跑通之后，可以按这个顺序升级：

1. 把 EEG 编码器从 GCN 换成 GAT
2. 把 mean pooling 换成 attention pooling
3. 把跨模态边从固定边升级为可学习边权
4. 把外周模态从单节点升级为多特征节点
5. 加入跨被试训练设置
6. 再扩展眼动和 EGG

## 七、当前结论

这版结构的意义在于：

- 它已经足够像一个真实模型
- 但复杂度仍然控制在可实现范围内
- 很适合作为你当前数据条件下的第一版原型
