# 模型输入输出定义

## 一、输入定义

本任务中，一个样本建议定义为：

- 一个固定长度时间窗口

例如：

- 2 秒
- 4 秒
- 8 秒

具体长度后续要根据你的采样率和任务需要再定。

## 二、输入模态

当前主输入模态：

- EEG
- ECG
- RESP
- EDA

未来可扩展模态：

- 眼动
- EGG

## 三、输入层级定义

## 1. EEG 输入

### 原始形式

- 多通道时间序列

### 推荐第一版输入表示

每个 EEG 通道提取一个节点特征向量，例如：

- PSD
- DE
- band power
- 时频统计量

这样可以得到：

- 节点数 = EEG 通道数
- 每个节点一个特征向量

## 2. ECG 输入

推荐先提取窗口级特征，例如：

- HR
- HRV
- RMSSD
- LF/HF 等

第一版可以把 ECG 作为：

- 一个模态节点
  或
- 若干 ECG 特征节点

## 3. RESP 输入

推荐先提取窗口级特征，例如：

- 呼吸频率
- 呼吸周期
- 振幅
- 稳定性

第一版也可作为：

- 一个 RESP 模态节点

## 4. EDA 输入

推荐特征例如：

- tonic level
- phasic response
- 峰值数量
- 峰值强度

第一版也可作为：

- 一个 EDA 模态节点

## 四、推荐的第一版输入组织方式

### 方案 A：节点级 EEG + 模态级外周输入

- EEG：
  - 每个通道一个节点
- ECG：
  - 一个节点
- RESP：
  - 一个节点
- EDA：
  - 一个节点

优点：

- 结构简单
- 最容易先跑通

### 方案 B：节点级 EEG + 特征组级外周输入

- EEG：
  - 每个通道一个节点
- ECG：
  - 多个特征节点
- RESP：
  - 多个特征节点
- EDA：
  - 多个特征节点

优点：

- 图结构更丰富

缺点：

- 节点定义更复杂

对于第一版，我建议先用 **方案 A**。

## 五、输出定义

输出要根据任务标签来定。

## 1. 分类任务输出

如果你的标签是离散情绪：

- 正/中/负
- 高/低唤醒
- 多类别情绪

那么输出就是：

- 一个分类概率向量

例如三分类输出：

- `[p1, p2, p3]`

## 2. 回归任务输出

如果你的标签是维度型：

- valence
- arousal

那么输出就是：

- 一个或两个连续值

例如：

- `[valence, arousal]`

## 六、建议的第一版输出任务

为了降低复杂度，我建议第一版先做：

- 二分类
  或
- 三分类

原因：

- 更稳定
- 更容易比较 baseline
- 更适合先验证图模型是否有效

## 七、样本级输出还是时间级输出

当前建议：

- 先做样本级输出

也就是：

- 一个时间窗口对应一个预测结果

后续如果要做动态情绪轨迹，再考虑时间级连续输出。

## 八、当前推荐的输入输出形式

### 输入

- EEG 通道节点特征矩阵
- ECG 节点特征
- RESP 节点特征
- EDA 节点特征
- 对应的图结构信息

### 输出

- 样本级情感分类结果

这是当前最适合作为第一版实验的定义。
