# 个体画像字段到个性化刺激策略映射表

日期：2026-03-30

## 文档目的

本文件用于回答一个核心设计问题：

- 问卷和反馈里收集到的个体画像字段，后续应如何真正用于个性化刺激设计

也就是说，本文件的目标不是继续讨论“收集什么信息”，而是进一步明确：

- 每类字段适合控制什么刺激维度
- 更适合用于候选库选择、参数配置、推荐优化还是生成式控制
- 哪些字段适合第一版最小系统
- 哪些字段更适合后续闭环系统

## 总体思路

当前建议把个性化刺激设计拆成 4 层：

1. 候选刺激层
   - 从已有视频、图片、音乐、场景模板中筛选候选内容

2. 参数配置层
   - 调整视觉风格、色调、镜头节奏、音乐类型、叙事母题等参数

3. 推荐与排序层
   - 根据用户画像和历史反馈，对候选内容做个体化排序

4. 生成与闭环层
   - 根据用户画像直接生成内容
   - 根据主观评分或生理反馈持续改写后续内容

## 字段分层原则

不同字段不应该被混用。

例如：

- `风险边界` 适合做硬约束，不适合拿去直接当生成风格提示
- `人格特质` 适合做高层偏好推断，不适合直接决定某个具体镜头
- `样例反馈分数` 适合做排序和闭环更新，比单次问卷更适合推荐层

因此建议把字段分成：

- 硬约束字段
- 高层画像字段
- 内容偏好字段
- 自我相关字段
- 实时反馈字段

## 一、硬约束字段

### 1. 风险与禁忌

字段示例：

- `risk_flags`
- `theme_blacklist`
- `negative_emotion_acceptance_level`
- `hard_constraints`

作用：

- 过滤掉不可呈现内容
- 限制刺激强度上限
- 决定系统是否允许进入负面情绪诱发流程

适合控制的刺激维度：

- 题材是否可用
- 声音强度
- 视觉刺激强度
- 镜头切换速度
- 是否允许出现创伤相关主题
- 是否允许出现高压场景

最适合用在哪一层：

- 候选刺激层
- 参数配置层
- 生成与闭环层

不建议直接用于：

- 推荐排序打分主干

原因：

- 它本质上是“安全边界”，不是“偏好强度”

第一版是否建议纳入：

- 必须纳入

## 二、高层画像字段

### 2. 基本信息与媒介经验

字段示例：

- `age_group`
- `language_background`
- `media_exposure_level`
- `content_format_familiarity`
- `vr_experience_level`

作用：

- 用于控制内容理解难度和媒介形式适配性
- 用于实验分层和结果解释

适合控制的刺激维度：

- 文本提示语言风格
- 叙事复杂度
- 内容长度
- 是否适合使用 VR 或 360 形式
- 是否适合使用实验性镜头语言

最适合用在哪一层：

- 候选刺激层
- 参数配置层

第一版是否建议纳入：

- 建议纳入

备注：

- 这类字段更适合做背景约束和实验控制变量，不应承担主要个性化任务

### 3. 人格特质与稳定心理特征

字段示例：

- `big5_openness`
- `big5_extraversion`
- `big5_neuroticism`
- `immersion_tendency`
- `sensation_seeking_level`
- `emotion_regulation_style`

作用：

- 用于推断用户对刺激强度、叙事风格和节奏的整体偏向
- 用于预测个体差异

适合控制的刺激维度：

- 情绪诱发强度
- 节奏快慢
- 感官刺激强度
- 故事抽象度
- 沉浸式程度
- 是否偏好安全、舒缓还是高唤醒内容

最适合用在哪一层：

- 参数配置层
- 推荐与排序层
- 生成与闭环层

不建议直接用于：

- 单独决定具体题材或具体视频素材

原因：

- 人格只能提供高层倾向，不能替代具体偏好

第一版是否建议纳入：

- 建议以简版纳入

## 三、内容偏好字段

### 4. 题材偏好

字段示例：

- `preferred_themes`

作用：

- 决定刺激内容的大方向

适合控制的刺激维度：

- 场景主题
- 叙事母题
- 人物关系线
- 物体与环境元素

最适合用在哪一层：

- 候选刺激层
- 参数配置层
- 生成与闭环层

第一版是否建议纳入：

- 必须纳入

### 5. 视觉风格偏好

字段示例：

- `preferred_visual_styles`
- `preferred_color_tones`

作用：

- 决定视频或图像的外观语义

适合控制的刺激维度：

- 写实或非写实
- 光照
- 色温
- 饱和度
- 电影感
- 梦幻感
- 复古感

最适合用在哪一层：

- 参数配置层
- 生成与闭环层

第一版是否建议纳入：

- 必须纳入

### 6. 节奏与声音偏好

适合控制的刺激维度：

- 背景音乐类型
- 环境音类型
- 声音密度
- 节拍强度

最适合用在哪一层：

- 参数配置层

## 四、自我相关字段

### 7. 自我相关场景与记忆线索

字段示例：

- `self_relevant_scenes`
- `self_relevant_relationship_themes`
- `self_relevant_symbols`
- `autobiographical_triggers`

作用：

- 提供真正高穿透力的个人化触发器

适合控制的刺激维度：

- 场景素材选择
- 叙事主题选择
- 象征元素植入
- 颜色、天气、时间、空间布局
- 音乐与环境声线索

最适合用在哪一层：

- 候选刺激层
- 参数配置层
- 生成与闭环层

第一版是否建议纳入：

- 强烈建议纳入

备注：

- 这是最值得和普通偏好分开的字段。
- 从文献上看，它往往比泛化偏好更接近真实诱发源。

### 8. 分情绪类别的触发映射

字段示例：

- `emotion_to_scene_map`
- `emotion_to_audio_map`
- `emotion_to_color_map`
- `emotion_to_narrative_map`
- `emotion_trigger_strength_matrix`

作用：

- 建立“目标情绪 -> 触发线索”的个体化映射

适合控制的刺激维度：

- 快乐使用什么场景
- 平静使用什么声音
- 悲伤使用什么叙事结构
- 紧张使用什么节奏和色调

最适合用在哪一层：

- 参数配置层
- 推荐与排序层
- 生成与闭环层

第一版是否建议纳入：

- 必须纳入

备注：

- 这是从“喜欢什么”走向“什么最能诱发哪种情绪”的关键字段。

## 五、实时反馈字段

### 9. 样例刺激反馈

字段示例：

- `sample_preference_scores`
- `sample_familiarity_scores`
- `sample_self_relevance_scores`
- `sample_emotion_labels`
- `sample_emotion_intensity_scores`
- `sample_rewatch_intention`

作用：

- 修正静态问卷的不准确部分
- 提供更接近真实反应的个体化证据

适合控制的刺激维度：

- 候选内容排序
- 推荐权重调整
- 生成 prompt 强化或抑制
- 刺激强度微调

最适合用在哪一层：

- 推荐与排序层
- 生成与闭环层

第一版是否建议纳入：

- 强烈建议纳入

备注：

- 如果只能在“多问几页问卷”和“加一个小型样例反馈环节”之间二选一，优先保留样例反馈。

### 10. 生理或行为反馈

字段示例：

- EEG
- ECG / HR / HRV
- EDA
- 面部表情
- 停留时长
- 再观看意愿

作用：

- 形成闭环优化证据
- 验证主观评分和真实反应是否一致

适合控制的刺激维度：

- 动态调整强度
- 动态调整节奏
- 调整后续场景或音乐策略
- 校正个体画像模型

最适合用在哪一层：

- 生成与闭环层

第一版是否建议纳入：

- 第一版可选
- 第二版强烈建议纳入

## 七、对子项目 01 的最小可行映射方案

如果当前只做第一版最小系统，建议只保留下面 6 类核心输入：

1. 风险边界
2. 题材偏好
3. 视觉风格偏好
4. 声音与节奏偏好
5. 自我相关线索
6. 样例刺激反馈

基于这些输入，系统先不要直接追求“完全自由生成”，而是优先做：

1. 候选模板筛选
2. 参数化 prompt 组装
3. 个体化排序
4. 小规模人工或自动反馈更新

## 八、建议的系统落地顺序

### 第一阶段：模板级个性化

做法：

- 先建立若干视频/场景模板
- 问卷字段只用于筛模板和调参数

特点：

- 稳定
- 好解释
- 实验容易控

### 第二阶段：推荐级个性化

做法：

- 引入样例反馈
- 根据实际反应做排序更新

特点：

- 比纯问卷更准
- 已经接近文献里的个性化刺激选择路线

### 第三阶段：生成级个性化

做法：

- 把画像字段映射成生成 prompt、镜头、音效、节奏控制变量

特点：

- 表达力更强
- 但更难验证

### 第四阶段：闭环级个性化

做法：

- 引入实时主观评分或生理反馈
- 根据反应动态调节后续刺激

特点：

- 最贴近真正的 personalized affective system
- 但工程成本最高

## 九、当前结论

基于现有文献和问卷设计，最合理的工程化路线不是一步到位做：

- “输入用户信息，端到端生成最懂他的情绪视频”

而是分层推进：

1. 用问卷和样例反馈先建立可解释的用户画像
2. 用画像做候选筛选和参数配置
3. 用反馈修正排序和触发映射
4. 再逐步引入生成式与闭环机制

这条路线更符合现有文献证据，也更适合形成可发表的研究设计。
