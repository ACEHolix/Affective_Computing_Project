# Search Strategy

## Objective

Build a reproducible literature search workflow for a review on EEG-based emotion recognition in affective BCI, with emphasis on machine learning and deep learning methods.

## Recommended Databases

- Web of Science
- Scopus
- PubMed
- IEEE Xplore
- ScienceDirect
- Google Scholar for gap checking only

## Core Search Concepts

The search should combine four concept groups:

1. EEG terms
2. emotion recognition terms
3. affective BCI terms
4. machine learning and deep learning terms

## Search Block Terms

### Block A: EEG

- EEG
- electroencephalography
- electroencephalogram

### Block B: Emotion Recognition

- emotion recognition
- emotion classification
- affective computing
- affect recognition
- emotion detection

### Block C: BCI Context

- brain-computer interface
- brain computer interface
- BCI
- affective BCI

### Block D: Methods

- machine learning
- deep learning
- neural network
- convolutional neural network
- recurrent neural network
- graph neural network
- transformer

## Recommended Search Strings

## Search String A: Broad Core Query

```text
("EEG" OR "electroencephalography" OR "electroencephalogram")
AND
("emotion recognition" OR "emotion classification" OR "affective computing" OR "affect recognition" OR "emotion detection")
AND
("machine learning" OR "deep learning" OR "neural network")
```

Use this as the main broad retrieval query.

## Search String B: BCI-Focused Query

```text
("EEG" OR "electroencephalography")
AND
("emotion recognition" OR "emotion classification" OR "affective computing")
AND
("brain-computer interface" OR "brain computer interface" OR "BCI" OR "affective BCI")
AND
("machine learning" OR "deep learning" OR "neural network")
```

Use this to retrieve papers that explicitly frame the work as BCI.

## Search String C: Deep Learning Trend Query

```text
("EEG" OR "electroencephalography")
AND
("emotion recognition" OR "affect recognition")
AND
("deep learning" OR "CNN" OR "LSTM" OR "Transformer" OR "graph neural network")
```

Use this to strengthen recent deep learning coverage.

## Search String D: Review Query

```text
("EEG" OR "electroencephalography")
AND
("emotion recognition" OR "affective computing")
AND
("review" OR "survey" OR "systematic review")
```

Use this only to identify related review papers and position the manuscript.

## Suggested Time Window

- Background and classic papers: before 2020 as needed
- Core analysis set: 2020-2026
- Optional emphasis set for trend discussion: 2024-2026

## Inclusion Criteria

- English-language papers
- Journal articles and strong conference papers
- Studies directly focused on EEG-based emotion recognition
- Studies using machine learning or deep learning methods
- Papers reporting dataset, model, and evaluation details
- Review papers can be used for background and positioning

## Exclusion Criteria

- Non-EEG-based studies
- Studies focused only on stress, fatigue, or workload without emotion recognition
- Papers without identifiable methodology or evaluation setup
- Duplicate records
- Abstract-only or inaccessible records
- Non-research items such as editorials unless needed for context

## Screening Workflow

1. Export search results from each database.
2. Remove duplicates.
3. Screen title and abstract.
4. Screen full text.
5. Tag papers by category:
   - review
   - classical machine learning
   - deep learning
   - multimodal
   - dataset paper
   - real-time or online BCI
6. Extract structured metadata into the literature matrix.

## Data Items To Extract

- title
- authors
- year
- venue
- dataset
- number of subjects
- number of channels
- emotion labels
- preprocessing
- features
- model
- evaluation setting
- metrics
- best reported result
- contributions
- limitations

## Quality Control Notes

- Verify whether reported results are subject-dependent or subject-independent.
- Verify whether validation splits are session-wise, trial-wise, or subject-wise.
- Mark papers with unclear methodology for later checking.
- Do not directly compare studies with incompatible datasets or protocols.

3. Run the review query to identify recent review papers.
4. Start a master spreadsheet with screened results.
