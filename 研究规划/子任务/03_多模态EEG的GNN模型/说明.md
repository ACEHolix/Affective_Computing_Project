# 子任务 03：适合分析多模态EEG数据的GNN类模型

## 任务目标

建立一个研究方向工作区，专门研究如何设计适合分析多模态 EEG 数据的 GNN 类模型。

这里的“多模态”可以包括：

- EEG + EOG
- EEG + ECG / PPG / GSR
- EEG + fNIRS
- EEG + 行为或视频特征

核心目标不是简单融合多种输入，而是研究：

- 不同模态之间的结构关系如何表达
- 图神经网络如何更自然地建模模态内和模态间关系
- 如何让模型在情感识别、状态识别或脑机应用中兼顾性能、可解释性和泛化性

## 问题定义

核心问题包括：

1. 多模态 EEG 数据中的节点和边应该如何定义
2. 如何同时建模 EEG 通道关系与跨模态关系
3. 如何处理不同模态之间采样率、时序长度和噪声水平不一致的问题
4. 如何让图模型对跨被试、跨场景设置更稳健

## 建议的系统工作流

1. 输入层
   - EEG 主模态
   - 其他辅助模态

2. 预处理层
   - 各模态单独清洗
   - 同步对齐
   - 时间片段切分

3. 图构建层
   - EEG 模态内图
   - 辅助模态内图
   - 跨模态连接图

4. 图表示学习层
   - GCN / GAT / 动态图
   - 多图融合
   - 跨模态注意力

5. 任务层
   - 情感分类
   - valence-arousal 回归
   - cross-subject 泛化

6. 评价层
   - 分类指标
   - 跨被试性能
   - 模态贡献分析
   - 可解释性分析

## 值得研究的创新点

- 多模态异构图建模
- EEG 主导的跨模态图融合
- 动态跨模态图结构学习
- 模态可信度驱动的图注意力
- 面向跨被试的多模态图泛化
- 融合图结构与情绪诱发场景信息

## 关键技术问题

- 多模态数据在时间和采样层面难以严格对齐
- 不同模态的信息密度和可靠性差异很大
- 图结构如何构建往往缺少统一标准
- 模型容易复杂化，但不一定真正提升可解释性或泛化性
